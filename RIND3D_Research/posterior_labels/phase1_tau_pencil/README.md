# RIND3D posterior labels — stage 2 (frozen-specification study, 2026-11-11)

Read `RIND3D_POSTERIOR_LABELING_REPORT.md` first. The mathematics is in `docs/METHOD.md`; all tables are
in `docs/RESULTS_TABLES.md`, regenerated by `code/make_tables.py` from `outputs/`.

**Engine.** The tau-pencil engine (TPE) gives exact 128³ cell masses of Uniform(F_W) for one window.
* `code/tpl/engine_b3.py` + `run_b3.py` — frozen; used for all Stage B numbers.
* `code/tpl/engine_v2.py` — development head; the same as b3 except for diagnostics.
* `code/rpl/` — the first study's package, frozen copy.

**Run** (CPU, numba). The study reuses the first study's venv:

    PYTHONDONTWRITEBYTECODE=1 ../RIND3D_PosteriorLabels/.venv/bin/python code/try_real.py <scene-prefix> <window-id>
    PYTHONDONTWRITEBYTECODE=1 ../RIND3D_PosteriorLabels/.venv/bin/python code/batch_real2.py --tasks outputs/tasks_val_random90.json --out <dir>
    PYTHONDONTWRITEBYTECODE=1 ../RIND3D_PosteriorLabels/.venv/bin/python tests/test_tau_lemmas.py

The canonical RIND3D package and campaign are imported read-only (`code/rpl/rindenv.py`).

**Tooling:**
* verification: `code/tpl/verify.py`;
* statistical baselines: `code/tpl/stat.py`;
* selection-law study: `code/selection_study.py` and `code/tpl/selection.py`;
* label format: `code/tpl/labels.py`;
* clearance shell: `code/shell_check.py`;
* cost model: `code/cost_model.py`.
