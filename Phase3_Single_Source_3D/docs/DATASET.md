# RIND3D data and coordinate contract

[Download the verified public RIND3D v0.1 archive](https://drive.google.com/file/d/1PmMp39En-uc4QTgACd_EpS4mTZ3wO7yx/view?usp=drivesdk), 633,273,091 bytes, SHA256 `1f5a2ff2bd9ac4a479a074b33e0d06f160706e4369b199144ee117693913ee1e`. From `Phase3_Single_Source_3D`, run `uv sync --extra train`, then `uv run python examples/download_dataset.py --output data`; open `data/RIND3D-v0.1`. The script verifies the archive and all extracted files before atomic installation. It can also use `--archive /path/to/RIND3D-v0.1.tar.zst`.

RIND3D is the permanent dataset name. v0.1 contains 1,000 distinct canonical geometries and 1,000 independently sourced scenes, each with 256 observations. There are 256,000 windows: 85,000 of side 64, 85,000 of side 128 and 86,000 of side 256. Future 2K/5K/10K releases do not rename the dataset. The initial profile is internally `Lite-Core-1K`; existing manifest/release IDs and the historical inner archive directory are preserved. The installer publishes that unchanged content under `data/RIND3D-v0.1`.

Geometry is continuous canonical binary64, independent of response-grid precision. One unit-strength point source illuminates FREE receivers whose closed segments do not intersect closed obstacles. Tangency and endpoint contact block light. The complete response and solid mask are losslessly stored by RINDPack; windows are coordinate views, not duplicated response arrays. A response zero may be either a solid voxel or shadowed FREE space. Use the local solid mask to distinguish them.

World coordinates use the unit cube. Source candidates are float64 **XYZ** in the open world `(0,1)^3`, FREE with clearance strictly greater than `2^-26`, and outside the selected observation. Voxel indices are integer XYZ; sample position is `(index+0.5)/1024`. Array storage is **ZYX**. Packed arrays have shape `(L,L,L/8)` and least-significant-bit X order. `Window.centres(local_xyz)` adds the integer origin before dividing by 1024. `voxel_centres` and `world_to_voxel` validate bounds and never clamp. Indexing is half-open `[0,1)`; continuous physical receivers may lie on the world boundary `[0,1]`.

Stored windows have integer `(x,y,z,L)`, only L=64,128,256, and half-open voxel extent `[origin,origin+L)`. No 64-brick alignment is assumed. For example, `(17,29,43), L=64` has first sample `(17.5,29.5,43.5)/1024`, and array `[z,y,x]` corresponds to local XYZ `(x,y,z)`. Every production window excludes truth and contains both lit and shadowed FREE voxels. The 256-window quotas are 85/85/86 and windows are unique within a scene. Source-space octree sizes describe a different object and do not alter this observation contract.

The teacher can explicitly access `data.teacher_scene(scene_id)`, whose canonical geometry is sufficient for independent candidate-source physics. Default `data[index]` returns only `scene_id`, `window_id`, `origin`, `side`, `observed_response` and `local_solid_mask`. `data.statistics(index)` provides exact lit/shadow/solid counts and `lit_ratio`; these are derived local statistics, not hidden-source labels. Metadata contains the public dataset identity and selected counts, never a full geometry payload. `make_dataloader` groups equal window sizes, stacks both local packed fields and transports NumPy arrays before parent-side Torch conversion. Use a main guard with multiple workers.

The public archive exposes full geometry and full response/solid targets by policy, while withholding serialized true sources, references, private witnesses and certification evidence. This is not a security sandbox: researchers can explicitly read privileged public targets. Training code must use the local-only adapter rather than handing the raw reader sample to the model. The raw `rind3d_reader.RINDDataset` preserves its older full-geometry interface for compatibility. No hidden true source is needed by Phase 3 source sampling or cost computation.

Splits are stable geometry-group hashes: first eight bytes (little-endian) of SHA256(`0/geometry_id/geometry-group-v1`) modulo 100, with 0–79 train, 80–89 validation and 90–99 test. v0.1 has 776/116/108 scenes, or 198,656/29,696/27,648 windows. Multiple windows and future sources sharing a geometry must stay together. The mixed observation policy has soft natural/uniform/extreme targets 30/50/20. Selection is distribution-changing; it is not unbiased accepted-uniform sampling or a guarantee that every scene has all ratio bins.

One fully independently verified truth is retained per window in restricted production, within the general 1–8 reference contract. It is only a compatibility witness. The 32/1024 minimum separation applies to stored optional reference labels, not arbitrary teacher candidates. Phase 3 creates no reference pool and searches no exact alternatives as an installation prerequisite. SDK integrity verifies bytes/CRC, while the frozen producer retains independent A/B physical evidence. These are different guarantees.
