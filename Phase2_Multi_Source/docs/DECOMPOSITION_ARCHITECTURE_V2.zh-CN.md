# Phase2 下一版解耦模型结构

日期：2026-10-29。**状态：已实现最小可运行版本；尚无新版全量训练效果或H20实测吞吐。** 现有训练、缓存和旧模型保留。自动搜索入口仍只搜索既有结构；新结构使用 `run_refined_masks_tmux.sh`，不混入旧搜索。详见 [运行说明](REFINED_MASKS_RUN.zh-CN.md)。

## 设计依据

本轮10万窗口扩展版：整体层数准确率87.75%、硬掩码IoU95.79%，但单层占62.5%。至少两层时计数准确率70.13%、IoU89.16%；至少三层时为43.62%、78.12%。宏平均形状高分不足以说明复杂解耦可靠。

错数窗口中154个少计、91个多计；按全部教师层汇总有261个漏层、116个额外启用槽。强度绝对MAE=0.04694，逐窗重建相对L1平均6.24%。低亮度场景存在绝对误差小、相对误差大的问题。不能由这些统计单独证明模型容量不足，但它们为结构改造提供了可检验的方向。

代码层面，当前纯解耦分支使用两级下采样的卷积/U形解码器，槽位读取池化至最多16×16的粗尺度特征，然后一次预测掩码、强度和存在性。其Phase1定位器关闭，Phase1的显式边界注意力并未自动参与本轮训练。

## 推荐主配置

先保留32槽，固定容量比较结构效果；全部教师标签继续保留，不截断为6层。其余推荐设置：隐藏维度256、4层槽解码块、8注意力头、3轮共享权重的同步细化、原生分辨率掩码。默认纯解耦模型实测 **12,325,731个参数**。H20吞吐和显存须在服务器运行后测量。

32是有效贡献容量，不是默认存在32个物理源。测试已出现20、22层算术标签，训练/开发的长尾也必须先审计。6/8槽作为后续容量消融，只能按训练/开发标签决定适用性。不能用本次测试删掉超容量样本后报告提升。

```text
局部总响应 y + 窗口位置/size W
              ↓
观测幅度归一化；保留原始幅度尺度 c
              ↓
响应区域编码分支 + 多尺度响应边界编码分支
              ↓
多尺度特征金字塔 + 原生分辨率像素特征
              ↓
32个对等槽位，256维，4层解码块，8头
              ↓
全槽同步细化3轮，跨轮共享解码参数
              ↓
每槽：单位掩码 M_i、存在概率 rho_i、强度 a_i
              ↓
重建 y_hat = Σ rho_i a_i M_i；同时输出存在性导出的层数分布
              ↓
后续阶段：实际启用槽的单位掩码 → 同一个共享Phase1定位器
```

## 1. 输入与幅度归一化

推断只读取局部总响应和窗口位置/size，不读取真实源编号、源位置、真实强度列表、教师层或教师残差。默认不输入局部/全场障碍物几何；教师障碍掩码只用于数据筛选和损失屏蔽。

对当前无噪声、正贡献模型：

\[
c=\max_p y(p)>0,\qquad u(p)=y(p)/c.
\]

全暗、全亮和无自由像素的窗口沿用当前数据侧筛选。数值实现使用与数据精度相符的epsilon，不以较大阈值删除弱贡献。

图像分支读取u、可由观测计算的正响应指示、局部像素坐标。窗口(x0,y0,size)仍提供世界坐标尺度信息。保留c供强度恢复；不能把归一化后的强度当成真实物理强度。

输入归一化使低亮度窗口的边界对比不至于相对坐标通道过弱。它不改变需要恢复的源数，不引入额外几何。纯解耦阶段没有候选源坐标，不能把Phase1的候选相对几何编码误当成本阶段的输入。

## 2. 响应与边界双分支

| 分支 | 输入/特征 | 目的 |
|---|---|---|
| 响应区域 | u、正响应指示、像素坐标；通道64/128/256/384，对应H、H/2、H/4、H/8 | 保留区域响应水平、空间关系和全局上下文 |
| 响应边界 | u的水平/垂直差分、梯度幅值及可学习卷积；通道32/64/128 | 强调细窄区域、额外响应跳变与弱层边界 |
| 多尺度融合 | 投影到256维，结合H/2、H/4、H/8信息 | 槽位直接读取细/中/粗特征，缓解只读粗尺度的问题 |
| 高分辨率像素解码 | 顶部融合与浅层跳接，输出128维原生H×H特征 | 输出与原视窗对齐的单位掩码 |

边界只是观测响应边界，不能称作已知障碍物边界。多个贡献可同时跨一条边界，不能默认一条边界对应一个源。

内存控制可采用分尺度规则网格token和边界加权池化；保留均匀区域token及原生像素解码。不要只保留全图最强的若干边界，避免弱边界完全消失。

## 3. 多头分工与软竞争读取

建议8头分为4头边界、2头响应区域、2头全局上下文。它们使用各自的key/value输入和角色编码，实现明确的读取分工；不是一个注意力头对应一个真实源。

对边界和区域读取，采用温和的跨槽竞争，再按每个槽在空间上归一化聚合消息。这样槽位能形成不同解释，但**竞争发生在特征读取，不是最终像素归属**。最终掩码均为独立sigmoid，允许多个槽同时覆盖同一像素。

例如y=(0.3,0.8,0.5)，两个层掩码可以为(1,1,0)和(0,1,1)。中间像素必须允许两层共同覆盖。不能对输出掩码做跨槽softmax，也不增加“掩码不能重叠”的惩罚。

全局头保持非竞争读取，为所有槽提供共同背景。保留槽间self-attention交换信息。不要无条件认定不同槽必须对应不同连通区域；一个层可含多个不连通支持。

## 4. 三轮全槽同步细化

每轮同时更新全部槽，而不是从一个槽开始逐层采样/剥离。

第一轮从原始观测特征给出初始掩码、存在性和强度。后续轮可读取自身预测的重建误差：

\[
\hat u^{(t)}=\sum_i\rho_i^{(t)}b_i^{(t)}M_i^{(t)},\quad
e^{(t)}=u-\hat u^{(t)},\quad b_i=a_i/c.
\]

保留正、负两种误差通道，用于提示遗漏和过量解释。误差来自模型自身预测，训练与推断均可计算；原始观测始终保留。这里没有最低正残差搜索、区域BFS、物理候选采样或某一槽先减掉的显式规则。教师残差不进入模型输入。

掩码引导注意力使用软门控而非硬裁剪，例如gate=0.1+0.9M，结合全局通路，让未覆盖区域仍可被读取。这样可避免初始错误掩码把弱层或不连通支持永久排除。具体门控强度在开发集消融。

3轮共享同一4层解码块及输出头；参数不随轮数乘3，计算量仍会上升。每轮均有辅助监督，使用最后一轮确定的匹配维护同一槽的跨轮身份。

## 5. 每槽的输出头

### 单位掩码

独立sigmoid输出M_i∈[0,1]。保留当前理想物理下y=0处贡献必须为0的门控。不要在正响应范围内施加未知区域为零的额外规则。掩码不乘层强度后再送定位器。

### 存在性与层数

存在概率rho_i由槽表示、全局上下文和掩码支持特征决定。保留由这些存在概率导出的Poisson-binomial层数分布及计数监督，不额外增加与槽存在性相矛盾的独立count分类器。

当前count分布argmax的86.75%低于0.5阈值计数的87.75%；不能直接宣称换成argmax会改善。激活阈值只在开发集校准，并与严格整窗指标共同验证。

### 掩码条件强度

强度头读取槽表示、掩码内外的响应/特征统计、边界跳变以及其他槽的重叠信息。掩码内的平均观测值包含其他贡献，不能直接当作当前层强度。

建议预测相对观测尺度的强度：

\[
b_i=\operatorname{sigmoid}(h_i),\qquad a_i=c\,b_i.
\]

这个上界有当前模型下的依据：任何非空真实层M_i，取其支持内像素p，有a_i≤y(p)≤max y=c。它不是把物理强度固定为1；c可大于1，因此有效贡献a_i仍可大于1。sigmoid端点饱和与现有softplus头需在开发集比较，不能未经验证宣称优于现有头。

对掩码相同或高度相关的层，仅凭总响应仍可能无法唯一估计各自强度；模型加大不能消除这种观测歧义。

## 6. 训练如何对齐

- 保持原始完整局部响应输入；教师全部层掩码、强度、存在性和残差序列只用于监督。
- 最后一轮做一对一Hungarian匹配，对同一份完整标签集合监督。最终匹配沿用到辅助轮，避免槽身份在细化途中无约束交换。
- 保留BCE+Dice掩码、正/空槽存在性、强度、计数与教师顺序残差监督；原始最低整体贡献不拆分，标签不改成真实源编号。
- 增加各轮掩码/强度/存在性辅助损失；按开发集比较辅助权重，最后一轮作为主输出。
- 重建同时考虑归一化响应的绝对误差与有数值下限的逐窗相对误差，防止只优化原始绝对MAE而忽略暗弱窗口。下限用于稳定训练，正式评估仍如实报告原定义相对误差。
- 保留负残差诊断及非负约束，绝不靠截断负值让评估看似正确。
- 训练按有效层数监控/适当均衡，特别是2层、3–4层。当前计数和存在性已占总损失相当部分，不能只根据准确率不足就无依据地把count_weight大幅调高。

结构收益必须用独立消融区分：现有结构 → 仅加宽/加深 → 加双分支/多尺度读取 → 加同步细化 → 加幅度与强度头改造。所有版本先统一32槽、同标签和相近优化预算。不能同时删困难窗口、改标签和改结构后归因于某个模块。

## 7. 与Phase1的衔接

本阶段只训练解耦。后续将实际启用槽的单位掩码与原窗口W输入同一个共享Phase1定位器，强度单独保留。首先使用与Phase1训练输入对齐的二值掩码，再独立评估软掩码接入。单贡献定位器的权重共享，不为32槽复制32个独立网络。

先测oracle教师层→Phase1，再测学生预测层→Phase1，才能分开定位器误差与解耦误差。算术层还需要单源物理可实现性检查；不能把位置兼容性不成立的标签自动视为真实单源。

## 验证与限制

验收同时看整体、至少2层和至少3层的严格整窗成功率、层数准确率、每层IoU与相对强度误差、重建和负残差。90%是目标，不是结构本身保证。特别保留长尾、弱响应与不连通支持案例。

本次2000测试窗已用于发现问题并提出新结构，后续可作历史基准。严格的最终确认还应保留未参与本轮诊断、且几何组独立的新测试场景，避免把反复反馈过的测试当成完全盲测。

bf16/TF32、原生尺寸分桶、激活检查点、GPU匹配、梯度累积仅在优化步骤结束同步等实现继续沿用。新结构尚未加入旧自动搜索；测量每配置吞吐、显存和优化步数，不通过盲目增大全局batch减少训练步数来追求利用率数字。

## 方法来源与RIND改造

- [Slot Attention](https://papers.nips.cc/paper/2020/file/8511df98c02ab60aea1b2356c013bc0f-Paper.pdf)：竞争读取和反复更新槽表示的思路。
- [Mask2Former](https://openaccess.thecvf.com/content/CVPR2022/papers/Cheng_Masked-Attention_Mask_Transformer_for_Universal_Image_Segmentation_CVPR_2022_paper.pdf)：多尺度高分辨率特征与掩码引导读取。
- [IODINE](https://arxiv.org/abs/1903.00450)：多对象表示的迭代细化思路。

本文的正贡献叠加、独立可重叠掩码、未知几何输入限制、幅度恢复和监督策略是针对RIND的设计提案。这些参考工作没有证明本文设计在RIND上达到某个准确率。
