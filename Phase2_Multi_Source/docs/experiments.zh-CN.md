# Phase II 实验流程与待办

数据和联合教师已导入，学生训练尚未实现。可以先安装/浏览多源数据并生成教师。实际命令见 [teacher.md](teacher.md)，研究定义见 [method.md](method.md)。

首次正式实验前应冻结：新数据 scene 划分、候选源数量及先验、每种源数的抽样数、位置 spacing、强度提案、温度与预算。当前配置中的这些研究参数仍为空，不能从场景真实源数偷偷设置。

上游 q 与 base_mass 成正比，再乘 exp(-C/tau)。base_mass 是源数量先验/采样测度，不是空间面积权重；不能因 Phase I 不乘面积而删除跨 K 的先验校正。

先验证联合教师的覆盖与不同采样规模稳定性，再实现排列不变的源集合能量模型、软分布训练、scene-balanced 评价。各源数对应的窗口数量不同，不能直接照搬每场景固定 18 个窗口的计数。教师使用隐藏几何筛选候选；学生概率范围需要另行设计并如实标注。

`./run_training.sh --check` 仍对应原始联合后验学生草案。逐层整合训练使用 `run_combined_training.sh`；完成后运行 `./view_results.sh` 浏览测试集教师/学生概率和逐层剥离。原始数据浏览继续使用 `./scripts/browser.sh`。
