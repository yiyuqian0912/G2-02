# 仅分层解耦训练：二次逻辑审查

版本标记：`phase2-decomposition-2026-10-28-v8-audited`。

## 审查结论

当前入口按“准备局部分层标签 → 原始多源响应输入学生 → 匹配完整有效层集合 → 训练掩码、强度、存在性与重建 → 最佳模型测试”执行。没有候选位置池、逐候选物理渲染、位置教师概率或 Phase1 定位网络。完整定位训练仍通过原入口执行，随后可加载本轮解耦权重。

本次没有改变最低正残差/BFS分层规则、网络结构、标签协议或损失公式。已有合法缓存与训练断点可以继续使用，无需因本次审查重新生成标签。训练中断时恢复上一个完整 epoch，尚未保存的当前 epoch 会重跑。

## 本次补强

1. 配置解析错误立即终止。旧入口在 shell 的条件判断中把所有非零退出都当作“不是仅解耦模式”，可能使配置错误进入完整流程的准备分支；现在严格区分有效模式与解析失败。
2. 仅解耦模式的定位损失权重必须为0，任务名必须合法，学习率和梯度裁剪必须有限且大于0。
3. 训练和评估开始前检查缓存schema、任务、槽位容量、实际数量、窗口坐标、层数/强度、重复视窗、跨集合场景、连续偏移与文件精确字节长度。缺文件或传输截断会在模型分配前报出对应文件。
4. 日志增加实际全局 batch：`每卡 micro × rank数 × 累积步数`，不再只能从目标 batch 推测。
5. 测试显式阻止候选渲染器、候选网格生成和 Phase1 模型实例化，避免只根据报告中的零渲染计数判断是否跳过教师。

缓存检查验证结构与长度，不会在每次启动时重读全部数据计算散列；不声称能发现任意同长度的磁盘篡改。缓存建立时逐窗检查算术重建，训练时检查损失和梯度有限性，断点与缓存/配置指纹绑定。

## 核心约定核对

| 环节 | 已核实的行为 |
|---|---|
| 观测 | 正强度、二值可见性叠加的总响应，保留连续响应强度；不把原始观测二值化 |
| 最低层 | 排除0，最低正值作为整体有效贡献，不主动拆成真实源 |
| 传播 | 复用原BFS；非相邻同强度区域不因数值相同直接合并 |
| 标签 | 当前层单位二值掩码；强度单独保存；未知/冲突诊断保留 |
| 残差 | 每次减去“该层强度×掩码”，验证非负和最终重建 |
| 真源 | 位置/编号/每源掩码不用于决定分层；数据读取器利用已有可见性形成观测总响应是数据读取，不是候选教师渲染 |
| 学生 | 只读取原始局部响应、坐标/窗口信息；默认不读取全场或局部障碍物输入通道 |
| 障碍物 | 用于生成自由空间邻接与屏蔽监督；薄障碍穿越不算普通自由空间邻接 |
| 槽位 | 独立可重叠掩码，允许一个像素属于多层；Hungarian一对一匹配掩码、强度和存在性 |
| 强度 | softplus正值输出，允许有效贡献强度大于1；有效层数不等于真实物理源数量 |
| 定位 | 仅解耦模式不构造定位网络、位置批张量或概率场；以后另行接入 |
| 验证/测试 | 不补齐重复样本；多rank使用未包装模型推理，空rank仍参与最终指标同步 |

目前`all_lit`沿用既有保守口径：所有自由像素响应均大于`1e-12`就跳过，即使这些正响应值不全相等。这会舍弃部分有信息的多源视窗，属于样本选择策略，不是可辨识性的必要条件。`all_dark`、无自由像素和未完成分层也不计入目标样本数。
