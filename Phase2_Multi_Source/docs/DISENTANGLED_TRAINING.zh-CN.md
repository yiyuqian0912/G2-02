# Phase2 v5：层数、形状、强度与重建分别监督

2026-11-02。新实验配置`configs/masks_disentangled.json`，后台入口`run_disentangled_masks_tmux.sh`。这是新的训练方案；本地执行检查不代表服务器测试准确率已经提高。

## 输入、答案与推断

学生只输入完整局部响应y和窗口位置/size。全场几何、真实源列表、教师层数、每层掩码与强度都不进入forward。障碍物掩码用于教师标签和损失/评价中的自由像素屏蔽，默认不作为学生输入。

教师仍提供原最低正残差/BFS算法产生的完整有效贡献集合`{M_t,a_t}`，掩码为0/1，并满足叠加重建。有效层数R不等于物理源数K；即便生成场景K≤4，当前标签R仍可能超过4。因此保留32槽，不截断高层样本，有效强度也不强行限制到1。

模型保留多尺度边界/响应编码、4/2/2注意力分工、3轮共享细化，增加一个读取全局像素特征及槽特征的计数分支。槽存在性仍逐槽输出，FP32 log空间计算其诱导的计数分布。

最终计数分类分数为：`槽计数log概率 + 全局计数分支分数`，再softmax。它是带全局修正的分类器，不解释为两个独立物理后验相乘。全局分支也接受独立的真实R交叉熵监督。新分支最后一层初始化为0；这是对每次readout的中性修正，不表示新模型完整forward与旧模型完全相同。

推断顺序：

1. 从原始响应计算掩码、各槽强度、存在性及计数分数。
2. 预测R取计数分布argmax，按存在性分数选择最高的R个槽；并列时按槽索引确定。
3. 启用槽的贡献为`a_t*M_t`，总重建为其叠加。**存在概率不再充当亮度乘数。**
4. 下一轮细化只读取该轮自身预测的重建误差，不读取教师残差。

全零响应可由观测直接确定没有可见贡献；正响应对应至少一层。训练标签仍按旧规则跳过全亮、全暗、无自由像素与未完成分层的窗口。

## 四项监督具体约束什么

所有任务共用一组完整集合Hungarian对应关系：形状代价加少量强度代价，包含空槽，不靠存在概率决定某个真层是否值得监督。各轮辅助损失共用最终轮对应关系，防止轮间任意换标签。

| 目标 | 默认损失 | 想达到的结果 |
|---|---|---|
| 层数与槽存在性 | 最终计数CE＋0.5×全局计数CE＋0.25×槽计数CE；另加0.5×存在性BCE（空槽项系数0.25） | 数量准确，每个真层对应启用槽，额外槽关闭 |
| 每层形状 | BCE＋Dice；按真层逐层平均 | 每层完整二值支持正确，小面积/弱亮度层也有独立监督；允许不同层重叠 |
| 每层强度 | `SmoothL1(log(a_pred/a_teacher), beta=0.1)`，实现时以窗口最大响应归一化并保留数值下限 | 强度相对误差受到直接约束，不用存在概率来补偿；不同强度层等权 |
| 整体重建 | 教师对应集合重建的归一化MAE＋0.25×实际预测启用集合的归一化MAE | 真层各自正确，同时实际推断输出能够重建观测 |

总损失为上表之和，外加0.25×中间两轮的平均同类损失。默认残差训练项权重为0，残差误差继续报告，避免多个重复重建目标遮蔽四项主任务。所有系数在`loss`中独立配置；这些是首版开发参数，不声称已最优。

“教师对应集合重建”只发生在loss：用匹配后的所有真层预测掩码和预测强度叠加，不乘存在概率。这样模型不能仅因少报一层，就让该层失去形状/强度监督。**这个重建不是实际部署输出**；实际输出始终用预测层数启用槽位，并单独评价。两种重建分别记录，不能拿前者冒充部署效果。

任务共享编码器和槽特征，所以优化并非数学上完全独立；本次解除的是目标含混和存在性/亮度乘法补偿，而非保证所有梯度互不影响。

## 指标、选模与结果位置

原缓存实验：`outputs/masks_disentangled_v5/`；新增实验：`outputs/masks_disentangled_v5_complexN/`。

- `progress.jsonl`、`models/seed_0/training.json`：各项loss、归一化监督/部署重建、强度相对误差、层数准确率、严格成功率及各R计数混淆矩阵。
- `models/seed_0/best.pt`：按计数分组宏平均选择；相对迁移后新模型epoch0，单层/总体计数下降≤0.5个百分点，软Dice下降≤1个百分点，逐层强度10%通过率下降≤1个百分点，严格整窗通过率下降≤0.5个百分点。
- `loss_best.pt`：另存新目标总验证loss最低权重；`last.pt`：断点。
- `evaluation/`：自然分布验证/测试上的计数、硬IoU/Dice、绝对/相对强度误差、全部层强度通过率、实际输出重建和严格整窗成功；分R、size、场景等权及场景bootstrap。
- `evaluation/initial_reference/`：真正的原v3模型，用原架构、原存在性解码、原重建方式在相同窗口重新评估。v5和参考共用固定形状/强度评价匹配，避免不同训练loss的匹配方式影响对比。
- `finetuning_comparison.json`和验证版本：同一评价口径的前后对比。新的固定匹配口径与旧报告不同，不能直接拼接旧报告数值。

迁移后的新模型epoch0已经采用新的启用和重建规则，不等同于未经修改的v3；真正旧模型基线在`initial_reference/`，不得混淆。新旧总loss定义不同，也不能直接比较总loss数值。

严格整窗成功仍要求启用槽与真层一一对应、每层IoU≥0.9、每层强度相对误差≤0.1、实际重建相对L1≤0.05。只把层数预测到90%不能称为90%完整解耦。

当前有效贡献教师未验证每层单源物理可实现性。源码检查、数值梯度、AMP、断点和小规模真实数据只能确认实现可以执行；正式精度结论以服务器固定测试集为准。

## 2026-11-03：按空闲显存自动选卡与实测微批

v5默认自动使用adaptive策略和batch探测，不固定GPU编号。GPU有常驻进程不再一票否决：连续3次采样均满足至少24GiB空闲、利用率不超过20%的卡进入候选，`--gpus auto`使用全部候选。各卡总/已用/最小空闲显存、近期最高利用率及排除原因打印到日志。其它旧模型入口保持旧默认，显式`--gpu-policy adaptive`也可使用新筛选。

```bash
./run_disentangled_masks_tmux.sh start train \
  --session rind_masks_disentangled_more \
  --gpus auto --gpu-policy adaptive --auto-batch
```

上述session来自之前扩充训练；不传新增N会读取它原来的配置，避免重试选卡时意外切回未扩充数据的版本。首次选择额外N仍需显式`--add-complex N`。

实测微批规则：

- 使用当前训练模型、训练集中最大原生size/较多层的一条记录；只在GPU复制为探测批，执行前向、loss、反向，不执行optimizer.step、不新增训练记录。
- 每卡按`当前空闲显存＋本进程已有预留显存`计算预算，留出至少6GiB或约10%的余量，另估算Adam/DDP增量；别的进程占用的显存不算入可用预算。
- 测试与当前目标有效全局batch相容的8/16/24/32/48/64/96/128/192/256等微批。所有rank遵循同一个候选序列；某rank OOM会清理本进程缓存并参与结果归并，不自行退出导致其他rank等待。
- 只在所有卡都容纳的候选中，按最慢rank的实测计算吞吐选择共同微批，不仅追求显存占满。没有计入真实DDP通信/磁盘时间，不声称是全系统最优。
- 每次恢复重新探测，保留模型/优化器状态，不复用过时的空闲显存测量。模型模式和随机数状态恢复，验证集和测试集不参与选择。
- 双卡、目标全局256时，32对应累积4步，64对应累积2步，128对应累积1步。改变可用卡数时仍按现有累积取整规则打印实际有效batch。

`gpu_batch_probe.json`记录各卡每个候选的实测峰值、显存预算、耗时与最终选择；历史在`runtime/gpu_probes/`。标定是额外的短时初始化，随后正常训练。

手动指定每卡微批时可用`--batch-size 64`，默认关闭探测；要恢复自动则加`--auto-batch`。`--gpu-reserve-gib 6`可调整预留，`--min-free-memory-mib 24576`和`--max-utilization 20`可调整筛选。固定微批属于运行参数，不改目标batch和loss，不会让旧checkpoint签名失效。

上一轮同类32槽/三轮结构在每卡32时曾测得约12.4GiB峰值；新版实际峰值以GPU标定为准。共享卡上别的任务可能之后增长，当前筛选不是独占资源承诺。不会杀掉其它进程或重置GPU。

本机无H20：实际状态表回放、不同编号选卡、分布式OOM归并控制、预算计算、无权重更新/随机数恢复和入口分发均做自动检查；真实H20显存/吞吐需要服务器生成探测报告。
