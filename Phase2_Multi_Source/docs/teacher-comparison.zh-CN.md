# 逐层教师与全场均匀网格穷举教师对比

在 Phase2 目录运行：

```bash
uv run --with scipy --with matplotlib python scripts/compare_teachers.py \
  --scene-id 39 --view-id 8 --spacing 256 \
  --counts 1 2 3 4 --temperature 0.01 \
  --beam-width 64 --samples-per-pattern 8 --seed 20261011 \
  --output outputs/teacher_comparison/scene39-view8
```

`--spacing` 是两种方法共同使用的全场规则网格间距。剔除窗口内部和障碍物内的位置后剩下 n 个位置。对每个 k，基线完整枚举 C(n,k) 个无序、不重复位置组合；不枚举重复位置，也不是连续空间穷举。四个 k 分别归一化，不推断源数量后验。

默认 `--max-combinations 100000` 限制四个 k 的组合总数，超限在渲染前停止。可显式提高预算，或增大 spacing。不要直接使用逐层教师的默认 spacing=16：对应的 C(n,4) 通常无法穷举。粗网格可能使逐层方法找不到可行解，这是实验结果；代码不会偷偷换用更细网格或真值位置。

## 强度和公平比较

对每组位置，用逐源二值可见性线性叠加，线性规划全局优化全窗口 MAE。强度约束默认 [1e-6,1]，用 `--min-strength` 修改下界。这是开区间正强度模型的数值近似；允许接近零的源会使较大 k 模型近似较小 k。每个组合等先验质量，q ∝ exp(-最优MAE/temperature)。这是强度优化后的 Gibbs 分布，不是积分掉强度的贝叶斯后验。

逐层教师沿用最低正响应区域及一阶毗邻区域的采样、减法和完整重建筛选。它自动结束，不保证生成每种 k。对每个 k，仅对该 k 下留下的结果条件归一化：

- **Layered actual**：原始逐层强度和教师权重，将相同位置组合的质量相加。
- **Layered positions, refit**：只保留逐层发现的位置组合，但采用基线的最优强度、等组合先验和同一温度，隔离位置覆盖的影响。
- 重复位置、低于基线强度下界的逐层配置不属于比较域，其概率另行记录；没有可比结果时不填造分布。

## 输出

- `comparison.png`：观测、障碍物，以及每个 k 的穷举分布、逐层分布、重拟合分布和差值，共用同一行色标尺度。青框为观测窗口。
- `report.json`：参数、数据路径、输入哈希、n、组合数、逐层失败详情、时间、每个 k 的指标。
- `distributions-k*.npz`：位置、完整位置组合、优化强度、MAE、联合组合概率及空间投影。
- `inputs.npz`：本次真实观测、窗口和逐位置单位可见性。
- `fit-k*-*.npz`：强度求解缓存；相同输入和脚本可重用。重复运行仍核验输入渲染。逐层教师有自己的渲染缓存，本脚本尚未跨两种教师共享它。
- `layered.npz`：成功时保存的原始逐层教师记录。

空间图是 **E[位置处源数量]/k**，全场和为 1；不是 k 源联合配置图，也不是真实像素分辨率。图按网格单元原样显示，不插值。源出现概率为该图乘 k（无重复位置时）。

同时报告联合配置与空间投影的 TV、JS_bits、overlap：前两者越小越相似（0 为相同），overlap 越大越相似（1 为相同）。`exhaustive_mass_covered` 是逐层发现的位置组合覆盖的基线概率质量；位置图相似不能替代联合配置相似。没有逐层结果时不定义相似度。

一个视窗的数值只描述该视窗、该网格、温度和强度界限。建议换不同场景和视窗，并改变 spacing、temperature、min-strength 做敏感性检查；不要把粗网格结果当作全数据结论。脚本不修改训练管线。
