# 逐层单源采样教师：首版

2026-10-11。此实现按讨论中的“最低响应连通区域＋一跳毗邻区域 → 全场单源采样 → 局部减法 → 重新分区”执行。它是新的教师候选生成模式；原来的联合随机教师保留用于对照。学生训练管线未修改。

## 每一层具体做什么

1. 读取 float64 总响应与障碍 mask。按近似等值响应求四连通区域；同时用真实几何排除连接线段穿过障碍的伪邻接。区域内值域不超过 `region_tolerance`。
2. 找到最低**正响应**区域。这里“最小”指响应强度，不是面积；相同最低值的多个独立区域按首像素的行优先顺序逐个处理。
3. 取该区域及所有一跳邻居作为本层采样约束。全场候选位置仍限于世界内、观察窗口外、障碍物外。
4. 候选源必须照亮起始区域；对每个邻居，候选源将其归为“照亮、保留本层贡献”或“不照亮、不保留”。默认要求区域内部可见性一致；不能只有区域中间一部分被照亮。零残差邻居必须不被照亮。
5. 按不同的“选中邻居集合”分组，每组采样若干源位置，形成不同分支。**不根据邻居响应更高就自动选择它。** 区域面积不作为候选先验权重。
6. 本层源强度等于起始区域的最低响应值。仅从起始区域和候选选中的一跳邻居减去这个值，保留其他区域；随后重新构造残差区域，合并残差相同且四连通的区域。
7. 迭代到残差归零或达到 `max_sources`。同强度但不相邻的区域不会仅因强度相等而合并，也不会自动标记成同一个源。
8. 将已选源在整个窗口重新渲染并相加，检查完整观测 MAE。只有完成全部层且通过最终阈值的组合才进入教师文件。

候选源可能在一跳邻域之外也产生响应。首版不扩大减法区域：那些响应仍保留在完整预测里，最终会接受检查。这有可能造成分支失败；不会把局部减法完成直接视为完整重建成功。

多分支搜索有上限。待处理分支优先按全图正向预测的过亮误差、剩余响应量排序，最多保留 `beam_width` 个；这是明确的启发式，不能保证不遗漏解。同一邻居集合内的候选位置使用固定随机种子、无放回均匀采样。

## 文件与接口

| 文件 | 作用 |
|---|---|
| `src/rind_phase2/regions.py` | 响应分区、几何安全邻接，保持同强度非连通区域的不同身份 |
| `src/rind_phase2/layered_teacher.py` | 逐层选择、按邻居集合分支、减法、终止、完整重建筛选 |
| `src/rind_phase2/physics.py` | `visibility_at(xy)` 缓存全窗口单源二值可见性，同一位置不重复渲染 |
| `src/rind_phase2/teacher.py` | `--method layered` 入口；两种教师共用 NPZ 输出与校验接口 |
| `configs/teacher_layered.json` | 可自定义的首版参数 |
| `scripts/plot_layered_teacher.py` | 显示每一步的减法前残差、减法区域、减法后残差和候选源的全窗口可见性 |
| `tests/test_layered_teacher.py` | 验证逐层顺序、同强度断开区域、远处重复照亮拒绝、预算与失败状态 |

候选生成不读取源真值参数、每源真值通道或参考解。观测、障碍物几何和任意候选的正向渲染是允许输入。

## 运行

在 Phase2 目录执行：

```bash
uv run --locked rind-multi-teacher --method layered \
  --scene-id 39 --view-id 8
```

手动设置参数：

```bash
uv run --locked rind-multi-teacher --method layered \
  --scene-id 39 --view-id 8 \
  --spacing 16 --max-sources 4 \
  --beam-width 16 --samples-per-pattern 2 \
  --max-final-mae 0.01 --seed 20261011 \
  --output outputs/teachers/layered-demo.npz
```

查看逐层图：

```bash
uv run --locked --extra diagnostics python scripts/plot_layered_teacher.py \
  outputs/teachers/layered-demo.npz
```

默认绘制最终 MAE 最低的候选；`--index 2` 可选择其他候选。图中白色为本层减法支持或可见性，灰色为障碍；最后一列特意显示实际单源全窗口可见性，便于发现它与局部减法范围的不同。

## 参数

| 参数 | 默认值 | 含义 |
|---|---:|---|
| spacing | 16 | 全场位置网格间距；减半约增加四倍候选，和世界边长是不同概念 |
| max_sources | 4 | 每个分支最多采样的源数/迭代层数；不是读取真实源数 |
| beam_width | 16 | 每层继续展开的分支数上限 |
| samples_per_pattern | 2 | 每种选中邻居集合抽取多少个位置 |
| region_tolerance | 1e-12 | 等值分区、归零的绝对强度容差 |
| local_mismatch_tolerance | 0 | 每个局部区域允许的错分像素比例；0 表示全部照亮或全部不照亮 |
| max_final_mae | 0.01 | 允许的全窗口平均绝对强度误差，含障碍零像素，与现有教师一致；严格检查可设 1e-12 |
| temperature | 0.01 | 已通过筛选的组合之间的兼容性 softmax 温度 |
| seed | 20261011 | 固定候选抽样序列 |
| max_source_renders | null | 不同位置的单源渲染预算；预算耗尽不输出未完成标签 |
| max_evaluations | null | 最终完整组合评价预算 |

`local_mismatch_tolerance>0` 会明确开启近似区域匹配，并记入元数据；不会在失败时自行放宽。网格坐标沿用已有 `spacing/2` 起点约定。

## 输出与失败

默认文件在 `outputs/teachers/layered-<scene/view/config-id>.npz`，并附带 `.layers.json`。NPZ 保持现有完整源组合、物理代价、概率和位置网格字段；`metadata.layer_traces` 与组合一一对应，记录每层源位置/强度、起始区域、选中邻居、减法掩码的行程编码及剩余响应。

编码 `removed_runs=[[start,length],...]` 对窗口按行展开的数组生效。区域 ID 只在当前层有效；重分区后应依赖掩码追踪，不能假设跨层 ID 不变。

权重为已保留完整路径上的等经验质量，再乘完整重建兼容性。相同完整配置合并质量；不是校正了真实源数先验的后验，不能把它的源数投影直接当作源数估计置信度。没有使用区域面积扩大某层的概率。

以下情况明确失败而不产生新教师标签，也不自动退回联合随机采样：

- 当前网格没有满足局部可见性约束的位置；这不等于连续空间无解，可减小 spacing 后重试。
- 最低正强度超过接口允许的单源强度上限 1；不擅自拆成多个同位置源或扩充物理强度范围。
- 达到层数上限仍有残差；或全图叠加误差超过阈值。
- 全暗/全障碍窗口没有可用于本方法的正响应起始区域；不凭空生成不可见源。

无完成分支时输出 `.failed.json`，包含失败计数、各层尝试、候选数与采样裁剪情况。预算错误不会保存未完成教师。已有输出文件不会因为失败被删除。

## 首版验证

39 项测试通过，其中 32 项为现有回归检查，新增 7 项覆盖逐层语义。0.3/0.8/0.5 例子先减去 0.3，再合并剩余相邻 0.5 区域；相同强度但断开的区域保持两次独立处理。候选对远处区域重复照亮导致重建不一致的分支被拒绝。

真实数据小检查选择四个带响应边界的 32×32 视窗（scene/view：993/11、39/8、132/3、48/15）。间距 32 时，39/8 与 132/3 得到完整组合，MAE=0；993/11 与 48/15 没有匹配候选。后二者改为间距 16 后均得到 MAE=0 的组合。因此默认使用间距 16，仍保留密度参数；这四个检查不是数据集成功率评估。
