# 有限像素预算下的动态观测与源定位

2026-11-01。已确认：预算为累计新增观测像素；动作是相邻移动和扩大视窗。目标是让同一场景的多次观测共同约束真实源坐标。

核心思路不是机械地把窗越开越大，而是判断“当前源位置还在哪个方向上不确定”，再选择能够补充约束、同时花费更少新像素的观测。例如当前只有一条阴影边界时，可能更值得沿边界继续观察或换到另一侧，而不是把大量预算花在同一片均匀响应上。这是选窗应学习的能力，不是预设每个场景都会成立的几何规则。

## 1. 当前代码做到哪里

目前完成的是可运行的主动观测环境和三种参考路径：随机、优先扩窗、沿已观测边界延伸。它们直接读取真实RIND响应，保存观测拼图、覆盖区域、路径、预算和耗时；没有训练新策略，也没有把路径演示冒充定位精度实验。

现有组件可以继续使用：

- Phase2分层学生：完整局部响应→若干有效层掩码、强度、存在性；
- Phase1定位学生：单层二值响应和窗口位置→全场位置概率；
- `train_view_sets.py`：已有被动集合蒸馏，供对照；
- `multiview.py`：已有跨窗关联与折扣概率融合，但其融合是启发式，不能保证正确处理重叠观测。

新环境独立于训练管线，不改动上述模型或正在运行的均衡微调。

## 2. 预算和动作的准确含义

令已经观测的像素集合为U，下一窗口为W，计费为：

\[
c(W)=|W\setminus U|,\qquad U\leftarrow U\cup W.
\]

首次64×64观测计4096像素；再次读同一区域计0；向右移动32像素的同大小窗口新增2048像素。64×64直接扩大到包含它的128×128，新增12288像素。窗口内部的障碍物像素同样计费：观测前不能免费知道它们在哪里。

默认动作：上/下/左/右移动当前边长的一半；边长扩大一倍（中心对齐，或四种包含旧窗的锚点）；停止。可用边长16、32、64、128、256、512、1024；越界动作禁止，不自动裁剪。无缩窗、无任意跳跃。

这是一条**传感窗口路径**，目前不计移动距离，也不模拟实体机器人避障。完全落在已观测区域内的移动允许免费执行，方便重新定位；使用独立的`max_steps`防止无限循环。预算耗尽时停止。不能把免费重复观测当成新证据。

公平比较必须使用相同场景、初始窗、预算、允许动作、最大步数；报告实际花掉的像素。不同方法提前停止时，在相同实际预算处比较，不能只比较终点熵。

## 3. 学生需要新增的两种能力

### A. 历史定位：已经看过的内容合起来说明什么

推荐使用“全场坐标上的已观测响应拼图+覆盖掩码”作为历史输入。响应和坐标进入现有多尺度编码器，覆盖掩码明确区分“没有看过”和“已经看到0响应”。定位模型读取这个去重后的观测集合；当前窗口和剩余预算额外交给动作策略。静态无噪声环境中，相同已观测像素和值应给出相同定位信念，不能只因重复访问次数或预算改变就更确信。保留原始响应幅值；若网络做归一化，要输入尺度，只能使用已观测值或固定物理量程，不能使用隐藏全场最大值。

不必每一步把1024×1024全部送入高分辨率网络：可将已观测分块编码并缓存，通过世界坐标和覆盖去重形成历史tokens，再由全场候选位置查询这些tokens。新像素更新相关块，原块不重复计证据。计算时的降采样不改变原生像素计费。

Phase2解耦结果和Phase1位置场可以作为辅助特征及初始化；原始响应历史必须保留，以免前一次错误解耦不可逆地污染后续定位。对多源不能把每个窗口的slot编号当作稳定源身份：同一物理源可能被拆成不同有效层，不同窗的slot顺序也不固定。

训练先固定已有分层/定位编码器，在同场景多视窗历史上学习历史融合，再小学习率联合微调。对于尚未稳定关联的贡献保留不确定性；不能无条件将所有层的位置图相乘。单窗内不同贡献的平均混合，与同一源的跨时间证据累积，是两种不同操作。

### B. 动作评分：在剩余预算内下一步看哪里

策略输入只含已观测历史、当前定位信念、剩余预算和候选动作几何。每个动作编码其世界位置、size、新增像素数、与已观测覆盖的关系；共享网络给动作评分。**不能先读取候选窗口的真实响应再在测试时选最好的那个。**

理想的信息增益是：

\[
I(\Theta;Y_{W\setminus U}\mid D_t,W),
\]

其中Theta为物理源集合，Dt为已观测历史。未知障碍几何需要作为隐变量处理；不能在部署时借用隐藏场景渲染来计算这个量。当前学生输出的等权位置混合图也不是完整Theta后验，所以其熵下降只能是代理指标。

第一版学习预测各候选动作的定位收益，并结合新增像素成本打分；成本为0的动作单独作为重新定位处理，不除以0。该贪心方法是基线，不保证全路径最优。若出现必须先经过低收益观测才到达高收益位置的情况，再训练包含剩余预算的价值函数/RL策略，学习长期收益。

先做单源闭环能隔离历史融合问题；之后必须在真实多源场景上验证完整响应→学生解耦→学生定位→选窗，不能以单源结果代替多源结论。

## 4. 必须补齐的训练分布

旧数据的四分树窗口往往由是否含源决定，旧定位训练主要假设源在窗外；训练还过滤了全暗或全正响应窗。这些都是主动扩窗会遇到的分布差异。

主动数据构建应从与真源无关的初始窗口出发，执行合法路径，**保留全暗、全亮、包含源的窗口并正常计费**。不能通过真实源坐标决定窗口是否合法，也不能免费跳过无信息观测。坐标候选范围应包含已经观测的区域；取消窗外硬掩码后仍需重新验证/适配原模型，不能只改mask就认定域偏移解决。

训练历史用随机、扩窗和当前策略混合采集，防止只会处理一种路径。训练/验证/测试按连续障碍几何组隔离；起点、预算、轨迹seed另存清单。与静态100k标签有关的cache可以继续保留，但新历史样本需单独版本化。

训练时可由真实源位置、隐藏几何或物理教师计算监督与动作收益；这些不能进入推理函数的输入。新动作的模拟响应可由已有逐源visibility bits裁剪、乘真实强度再求和，**不需要每条路径重新做全场候选射线渲染**。精确物理位置教师若另行使用，需要独立计算/缓存；当前演示不生成此类教师。

## 5. 推荐执行顺序和验收

1. **观测接口**：本次已实现。核对新增像素、缓存、非法动作、未来信息隔离；用真实数据运行参考路径。
2. **历史定位实验**：固定随机/扩窗路径，比较单窗、现有折扣融合、覆盖去重后的历史模型。先证明同样观测预算下多视窗能提高定位正确性。
3. **学习选窗收益**：只在训练/开发场景做模拟动作分支，保存收益标签；部署策略只读公开状态。冻结测试场景，比较随机、固定扩窗、边界延伸、学习策略。隐藏几何的oracle选窗只作为上界参考，另行标记。
4. **长期策略**：确认贪心被路径约束限制时，再做RL或多步规划。大量候选分支的响应裁剪/网络推理可批处理到GPU；控制状态和文件I/O保留轻量CPU处理。当前没有H20实测，不承诺吞吐数值。

不以“分布越尖越好”验收。至少报告：

- 真源定位Recall@16/@32、每源匹配距离、漏源和多报（物理K与有效层R分开）；
- 真源是否落在预测核心区，核心区面积与覆盖率的共同变化；
- 同预算下的定位误差、漏源率，以及随累计新像素预算变化的曲线和曲线面积；
- 达到指定定位容差所需像素数、实际预算使用量、路径步数、每步推理时间；
- 有效层分解质量和关联歧义，避免把上游失败隐藏在最终平均图中；
- 按K、初始窗/最终窗size、源是否进入观测范围分层；独立几何场景聚类bootstrap。

开发时可用16,384/32,768/65,536/131,072像素等预算，统一64×64初始窗；起点应独立于真源。先在小批独立开发场景确定参数，再冻结到留出测试。无衰减遮挡模型可能存在无法消除的等价源位置，所以不保证每个场景收敛成一个点；需要保留物理不可辨识性。

## 6. 最小运行命令

从G2-02根目录，用现有Python环境运行：

```bash
export RIND_PYTHON="$PWD/Phase1_Single_Source_Single_Intensity/.venv/bin/python"
./run_active_observation.sh \
  --data-root Phase2_Multi_Source/data/raw/phase2-multi-source \
  --scenes 0 1 2 \
  --initial-window 480 480 64 \
  --budgets 16384 65536 \
  --policies random grow boundary \
  --seed 20261101 --annotate-truth \
  --output Phase2_Multi_Source/outputs/active_observation_demo
```

服务器如使用联合数据，把`--data-root`换成实际安装的联合目录即可；不假定服务器路径和本地相同。程序通过`dataset_update.open_dataset`读取，逐源乘强度求和；不用底层OR可见性充当总响应。它根据用户给定场景清单运行，不声称三个场景有总体代表性。

结果包含`parameters.json`（路径/manifest哈希/seed/参数）、`summary.json`、每条路径的JSON/NPZ/PNG。PNG展示已观测响应、覆盖/移动路径与累计像素，不包含虚构的预测概率场。绿十字仅在整条路径完成后用于真源标注。未知区域在数组中为NaN，图中为灰色；公开状态不提供全场障碍物、每源掩码或真实K/强度。

输出目录非空时拒绝覆盖；重跑请指定新目录。演示无需训练和教师候选缓存；要查询新位置仍需要原始RIND响应数据。这里是短时路径演示，无后台训练入口；后续正式历史/策略训练沿用项目tmux规范。

## 7. 文件对应关系

| 文件 | 负责什么 | 达到什么目标 |
|---|---|---|
| `research/active_observation/observation_env.py` | 合法动作、唯一像素预算、观测缓存、公开状态 | 不越预算、不免费窥视新窗口、重叠像素不重复计数 |
| `research/active_observation/active_policies.py` | 随机/扩窗/已观测边界延伸三基线 | 提供独立于源真值的路径对照；未来学习策略复用公开状态接口 |
| `research/active_observation/demo.py` | 真实RIND响应读取、路径运行、结果和图 | 可重复检查真实路径，不冒充定位性能结果 |
| `research/active_observation/test_observation_env.py` | 预算、动作、静态一致性、未来隔离等测试 | 覆盖错误动作、重复观测和异常响应等关键边界 |
| 根目录`run_active_observation.sh` | 选择现有Python环境和模块路径 | 仓库/最小服务器包使用同一条命令 |

本次**已实现并验证**的是环境/参考路径；**待训练验证**的是历史模型与学习策略的定位收益；**不宣称已解决**的是最优全路径、所有有效层跨窗身份、多源精确联合后验和不可辨识场景的唯一定位。

相关方法参考：[Deep Adaptive Design, ICML 2021](https://proceedings.mlr.press/v139/foster21a.html)、[Sequential Experimental Design with Deep RL, ICML 2022](https://proceedings.mlr.press/v162/blau22a.html)。这些研究支持将历史与预算纳入设计策略的方向；不意味着其假设或可微模拟器训练可直接套用RIND硬遮挡。

## 8. 本机已运行的检查

本地原10k多源数据，场景ID按0、1、2顺序取样（事后确认K分别为1、4、3）；每场景运行两档预算16,384/65,536和三策略，共18条完整路径。初始窗固定`(480,480,64)`，seed=`20261101`，原始manifest SHA256为`ed99427bb48183c0b9dd0f5f97349358befc9548f4fec9563a726b5c40b2893a`。

18条路径全部通过额外的逐步覆盖并集复算：每步新增像素数、累计计费和最终NPZ coverage一致，未超预算，未知响应全部为NaN。16条耗尽预算；2条因离散动作找不到可负担的新区域而提前停止，实际使用15,360和64,512像素，未把未使用部分补记成已用预算。源位置仅在路径完成后加到图上。

这只是接口与数据通路检查，**没有定位误差、信息增益或策略优越性结论**。耗时写入每条路径JSON；本机内存映射缓存命中下的毫秒级响应裁剪不代表服务器完整定位/训练速度。另有13项自动检查，包含预算事务、非法/免费移动、静态重叠、隐藏区域变化不影响动作及逐源强度叠加适配。
