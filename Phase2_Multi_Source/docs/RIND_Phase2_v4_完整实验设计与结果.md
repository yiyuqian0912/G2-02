## 1. 研究目标

RIND Phase II 研究二维遮挡环境中的多驱动源反演。场景中的每个驱动源具有正强度，源对可见像素产生贡献，多个源的贡献线性叠加：

\[
y(p)=\sum_{j=1}^{K}a_jV(p,s_j),
\qquad a_j>0,\quad V(p,s_j)\in\{0,1\}.
\]

其中，\(p\) 是局部视窗中的像素中心，\(s_j\) 是第 \(j\) 个源的全场位置，\(a_j\) 是源强度，\(V\) 是由场景障碍物几何决定的二值可见性。当前物理模型没有距离衰减、反射、材料差异和观测噪声。

最终目标是从一个或多个局部视窗逐渐恢复真实驱动源位置。当前版本先解决其中的基础学习问题：

1. 将多源局部响应通过残差剥离转换为若干二值有效贡献层；
2. 把每个二值层作为一个 Phase I 风格的单源定位任务；
3. 训练一个共享学生模型，预测该层在全场候选位置上的概率分布；
4. 在多层视窗中分别推理各层，再生成一张用于展示和比较的全场汇总场。

当前学生学习的是“单个残差层对应的源位置可行性场”，不是直接从原始多源响应联合预测所有源，也不输出完整多源联合后验。

## 3. 总体实验流程

```text
真实多源场景与局部响应
        ↓
过滤全亮、全暗和无自由像素窗口
        ↓
对局部响应进行逐层残差剥离
        ↓
得到多个“有效强度 + 二值支持掩码”
        ↓
每个窗口只做一次全场均匀候选可见性渲染
        ↓
同一批候选分别与所有二值层计算 Phase1 物理代价
        ↓
每层得到一个归一化教师位置分布
        ↓
筛选高置信信息层作为单源学生训练样本
        ↓
学生：二值层响应 + 窗口位置 + 候选坐标 → 候选能量
        ↓
softmax 得到每层学生位置分布
        ↓
多层教师/学生分别逐点 max，再归一化为汇总场
        ↓
概率、几何区域和真实坐标三层评估
```

## 5. 逐层残差分解教师

### 5.1 每轮最低正贡献

初始化 \(r_0=y\)。第 \(t\) 轮在自由像素中选择最低正残差：

\[
a_t=\min\{r_t(p):r_t(p)>\varepsilon\},
\qquad \varepsilon=10^{-12}.
\]

零响应阴影不作为贡献层。若有多个不相邻的相同最低值区域，算法不因强度相同而直接合并；种子取行优先顺序中最早的区域，其他不相连区域继续留在残差中。

### 5.2 区域图与传播规则

每轮在当前残差上重新构造近似等值四连通区域与邻接图。BFS 仅追踪“当前强度 \(a_t\) 是否仍存在”，不联合恢复其他源标签：

- 跨边响应相等或升高：当前层继续存在；
- 响应下降且下降量约等于 \(a_t\)：当前层退出，该分支停止；
- 目标区域响应小于 \(a_t\)：当前层必须退出；
- 其他下降：下降归因于途中新增的其他贡献退出，当前层继续存在；
- 不同路径对同一区域产生存在/退出冲突：该区域标为 unknown/conflict，不加入当前层。

本轮 BFS 正区域构成二值层掩码 \(M_t\)。随后执行：

\[
r_{t+1}(p)=r_t(p)-a_tM_t(p).
\]

更新后重新分区并开始下一轮。若出现显著负残差、状态异常、超过最大层数或最终残差不能清零，则窗口标记为 incomplete，不进入正式训练记录。

### 5.3 方法边界

“下降量等于当前层强度时当前层退出”是当前确定性启发式，不是一般遮挡几何中的无条件定理。精确同强度贡献、混合切换、贡献退出后在远处重新出现，都可能造成歧义。当前版本显式记录冲突和失败，不读取真实源编号修正传播。

## 6. 单次全场采样与每层物理教师

### 6.1 统一候选网格

所有恢复层完成后，每个窗口只生成一次统一全场候选网格：

- spacing = 8；
- 128×128 网格；
- 每层 16,384 个候选位置；
- 所有层严格共享候选坐标和数组顺序。

候选位置的单位强度可见性只渲染一次，然后同时用于所有层的评分。昂贵的几何渲染次数因此不随恢复层数重复增长。

### 6.2 阴影筛选

原始观测中自由像素且总响应为零的位置满足：所有真实正强度源在该像素都不可见。因此，如果候选源会照亮任意这类像素，该候选被永久排除。障碍物内部的零值不参与该规则。

该筛选在当前正强度、无噪声、线性叠加模型下是严格物理约束。

### 6.3 每层物理代价

每个保留候选的单位可见性掩码与当前二值层 \(M_t\) 比较：

\[
C_t(s)=\alpha L_{\mathrm{resp}}(M_t,V_s)+\beta L_{\mathrm{edge}}(M_t,V_s).
\]

正式配置为：

\[
\alpha=1,\qquad \beta=0.
\]

因此当前教师使用**边界加权的响应平均绝对误差**：`boundary_lambda=2`、`boundary_sigma=1` 在 CPU 与 CUDA 路径中都生效。CUDA 快速路径利用二值可见性的代数等价式将该代价改写为矩阵运算，但不会取消边界权重。`beta=0` 仅表示当前没有启用独立的边界集合距离项 \(L_{\mathrm{edge}}\)。

每层教师概率为：

\[
q_t(s)=\frac{\exp[-C_t(s)/\tau]}{\sum_{s'}\exp[-C_t(s')/\tau]},
\qquad \tau=0.05.
\]

每层概率质量单独归一化为 1。有限 spacing=8 网格不要求存在零误差候选；没有精确候选时仍根据相对物理代价产生软分布。

### 6.4 GPU 教师

教师使用 6 张 NVIDIA H20 96 GB GPU。候选合法性、可见性、阴影筛选、多层响应代价和 softmax 在 GPU 上批量执行。候选渲染以窗口为并行单位分配到不同 GPU，同一窗口内对候选批处理。

## 8. 学生模型

### 8.1 输入与输出

学生输入：

1. 当前残差层的二值响应图；
2. 局部窗口的世界坐标 `(x, y, size)`；
3. 局部像素坐标通道；
4. 查询候选源位置 `(s_x,s_y)`。

学生不接收全场障碍物几何。`use_obstacle=false`，因此隐藏障碍物只存在于教师物理监督中，不作为学生输入。

学生输出条件能量：

\[
E_\theta(M_t,w,s),
\]

并在完整 16,384 候选世界网格上归一化：

\[
p_\theta(s\mid M_t,w)=
\frac{\exp[-E_\theta(M_t,w,s)]}
{\sum_{s'}\exp[-E_\theta(M_t,w,s')]}.
\]

### 8.2 网络结构

正式 v4 使用 Phase I baseline `SourceEnergyField`：

- hidden size：128；
- Fourier frequencies：6；
- 观察编码器：三层卷积，其中两次 stride-2 下采样；
- 窗口编码器：两层 MLP；
- 候选坐标：归一化世界坐标 + Fourier 特征；
- 候选 query 与观察 token 通过 scaled dot-product attention 交互；
- energy head：三层 MLP 输出每个候选的标量能量；
- normalization support：`world`。

`world` 表示学生必须在完整世界候选网格上分配概率，不能使用教师隐藏几何直接排除障碍物内或物理无效位置。这一设置使任务更困难，但符合“学生推理时不知道全场几何”的研究目标。

### 8.3 训练目标

训练最小化教师到学生的交叉熵：

\[
\mathcal L_{\mathrm{CE}}
=-\sum_s q_t(s)\log p_\theta(s\mid M_t,w).
\]

当前版本没有把 Dice、IoU 或硬阈值区域损失加入训练；几何指标只用于评估。这避免了阈值选择直接改变训练目标，同时保留概率校准能力。

### 8.4 训练超参数

| 参数 | 数值 |
|---|---:|
| Seed | 0 |
| 最大 epochs | 100 |
| Early-stopping patience | 15 |
| Batch size | 96 |
| Learning rate | 0.001 |
| Weight decay | 0.0001 |
| Gradient clipping | 1.0 |
| Hidden | 128 |
| Fourier frequencies | 6 |
| Candidate chunk | 4096 |
| Precision | FP32 |
| Optimizer | AdamW，非 fused |
| GPU | 6×H20 |

训练共执行 51 个 epoch，并因早停结束。最佳验证模型出现在 epoch 36。

## 9. 多层汇总场

多层视窗中，每层分别通过同一个单源学生得到 \(p_t(s)\)。教师和学生使用完全相同的汇总规则：

\[
P_{\max}(s)=
\frac{\max_t P_t(s)}{\sum_{s'}\max_t P_t(s')}.
\]

每层在取最大值前已经单独归一化，不按恢复强度加权。max 保留任意一层给出的强位置假设，避免不同独立贡献被平均稀释。

该汇总场只用于热点展示和教师/学生比较。它不是：

- 多源位置的联合后验；
- “该位置至少存在一个源”的占用概率；
- 各层相互独立的数学证明；
- 可用于枚举源组合的完整分布。

教师缓存中的旧 `equal_layer_mixture` 元数据不作为 v4 学生标签。v4 直接读取每个 `layer-XX.npz` 的单层概率，并对教师层和学生层统一应用上述 normalized max。

## 10. 评估协议

### 10.1 覆盖范围

正式评估覆盖：

- 2,605 / 2,605 个测试窗口；
- 5,727 个信息层；
- 753 个独立测试场景；
- 4,960 个高置信层和 767 个低置信层；
- 16、32、64、128 四种窗口尺寸。

真实源坐标只用于最后的评估标注，不参与残差传播、教师概率、学生输入或预测计算。

### 10.2 三类指标

1. **概率拟合：** CE、KL、JS、TV、probability overlap、Bhattacharyya、Hellinger、cosine；
2. **几何形状：** 教师/学生 50%、90%、95% 最高密度区域的 Precision、Recall、Dice、IoU；
3. **坐标定位：** NMS 后与真实有效源进行一对一距离匹配，报告 Recall@8/16/32 和距离。

主要几何指标采用 90% 最高密度区域。Recall 衡量教师区域被学生覆盖的比例；Precision 惩罚学生额外画出的区域；Dice 和 IoU 综合两者。

置信区间通过 1,000 次 bootstrap 计算，以独立 `scene_id` 为聚类单位，不把同一场景中的窗口当作独立样本。

### 11.2 多层汇总场的主要结果

| 指标 | 均值 | 95% scene-bootstrap CI |
|---|---:|---:|
| Shape Dice@90 | 43.76% | 42.61%–44.69% |

源数增加时几何 Dice 上升，但真实坐标误差也上升。这进一步说明区域重合不能单独代表最终定位能力。

| 指标 | 学生 | 教师 |
|---|---:|---:|

## 12. 结果结论

当前模型已经学到稳定且有意义的单视窗几何约束：

- 测试表现显著优于均匀预测；
- 验证与测试差距小，没有明显过拟合；
- 汇总场覆盖约 83.5% 的教师 90% 高密度区域；
- 高置信层的表现稳定优于低置信层；
- 100 个可视化样例的结果与全测试集统计一致。

当前主要缺陷是概率场过度扩散：

- 学生 90% 区域约占全场 52.6%，教师约占 27.0%；
- Precision 只有 35.1%；
- 41.7% 的学生概率落在教师无效候选上；
- 学生熵明显高于教师，核心热点排序差异较大；
- 单视窗真实坐标误差仍然很高。

因此，当前版本应定义为：

> 学生能够从二值残差层恢复教师位置场的大致几何形貌和方向，但尚未充分排除错误位置；单个局部视窗只能提供宽泛约束，不能独立完成真实源坐标恢复。

## 17. 第二轮全场几何实验及诊断（v5）

### 17.1 实验目的

v5 在与 v4 相同的残差层、候选网格、教师标签和场景划分上，额外输入完整场景障碍物 primitive。它用于回答：学生得到完整障碍物几何后，是否能够减少错误候选区域并提高位置场精度。

| Test CE | 8.813449 | 8.827647 | +0.014197 | 越低越好 |
| Forward KL | 1.395267 | 1.415633 | +0.020366 | 越低越好 |
| Information recovery | 0.397040 | 0.390711 | -0.006329 | 越高越好 |
| Dice@90 | 0.437550 | 0.431409 | -0.006142 | 越高越好 |
| Recall@90 | 0.834867 | 0.838617 | +0.003750 | 越高越好 |
| Precision@90 | 0.350770 | 0.343962 | -0.006808 | 越高越好 |

### 17.2 几何置乱诊断

诊断固定局部响应、视窗和候选位置，只在 batch 内循环置换完整场景几何。最佳 v5 checkpoint 为 epoch 54，共检查 120 个来自不同场景、按窗口尺寸分层选择的测试层。

| 项目 | 结果 |
|---|---:|
| 正确几何 CE | 8.949366 |
| 置乱几何 CE | 8.949612 |
| 置乱 − 正确 CE | +0.000246 |
| 配对差值标准误 | 0.02172 |
| 近似 95% 区间 | [-0.0423, 0.0428] |
| 正确几何更好的样本比例 | 47.5% |
| 置乱后的平均 probability TV | 0.1035 |

数据接口、checkpoint 配置和每个 batch 的几何输入均已核验。几何参数相对初始化发生明显变化，置乱后概率场平均移动约 10.35% 的概率质量。这说明模型不是完全忽略几何；但正确几何没有比错误几何稳定降低 CE，说明模型学到的是不可靠或不可泛化的几何依赖。

原诊断脚本中“TV 接近零等于忽略几何”的说明只适用于 TV 确实很小时。当前 TV=0.1035 不能称为接近零。v5 的正确判定是：**模型对几何敏感，但没有学会正确使用几何。**

### 17.3 v5 失败的主要原因

1. v5 batch size 为 768，每个 epoch 约 57 次参数更新；最佳 epoch 54 只有约 3,100 次更新。v4 batch size 为 96，最佳 epoch 36 约有 16,200 次更新。
2. v5 从随机初始化重新训练，并改变整个 energy head。新增几何分支训练失败时，会同时破坏已经有效的 v4 局部定位能力。
3. 候选位置只通过一次候选到障碍物 token 的交叉注意力读取几何。精确可见性取决于候选源、障碍物和视窗像素之间的射线关系，原始 primitive 参数并没有直接提供这种关系。
4. v5 使用 `use_obstacle=false`，局部图像编码器没有直接读取局部障碍物 mask。
5. 随机场景中，同一 primitive 形式和局部响应之间容易产生训练集相关性，但这种相关性不一定能推广到未见场景。

## 18. v6 双模式总体设计

实际应用以**完整几何不可见**为主要设定。完整几何可见模式作为上限实验、诊断工具和训练期特权教师。两个模式共享同一个 Phase I 单层定位核心。

### 18.1 模式 A：几何不可见，作为正式部署模型

每个局部视窗继续执行：

```text
多源响应 → 残差分层 → 每层 Phase I 单源位置分布
```

同一场景获得多个视窗后，不再对视窗结果取最大值。对于被关联为同一有效贡献的层，使用加权能量相加，也就是 log opinion pool：

\[
\log \tilde P_j(s)
=\sum_{i\in\mathcal T_j}w_i\log P_i(s),
\qquad
P_j(s)=\frac{\tilde P_j(s)}{\sum_{s'}\tilde P_j(s')}.
\]

其中 \(\mathcal T_j\) 是第 \(j\) 个贡献在不同视窗中的轨迹。若各视窗在给定源位置后条件独立且先验处理正确，\(w_i=1\) 对应后验乘积。真实重叠窗口共享未知障碍几何，并不严格独立，因此首版使用相关性折扣 \(\rho=0.5\)，令总有效证据权重为 \(1+\rho(m-1)\)，再平均分配给 \(m\) 个视窗。它会温和收缩一致候选，同时避免完整概率乘积过度自信。该融合结果在独立性未经验证时称为组合证据分布，不宣称是真实联合后验。

若位置先验不是均匀分布，需要对额外视窗重复引入的先验进行扣除：

\[
\log \tilde P_j(s)
=\sum_iw_i\log P_i(s)
-\left(\sum_iw_i-1\right)\log \pi(s).
\]

不同视窗的残差层采用保守软关联。首版依据：

- 两个位置概率场的 Bhattacharyya overlap；
- 去除均匀背景后的 centered cosine shape similarity；
- 概率场相对均匀分布的 total variation 信息量折扣，防止两个近似均匀场仅因同向数值扰动被误关联；
- 有效贡献强度的软一致性；
- 每条轨迹在一个视窗中最多包含一个层；
- 聚类合并采用 complete-linkage：两个已有轨迹之间的所有跨轨迹层对都必须通过阈值，不能只靠传递链合并；
- 关联证据不足时保留为独立轨迹，不强制合并。

一般层对使用关联分数阈值 0.55。若两个有效贡献强度在相对容差 \(10^{-6}\) 内完全一致，则使用 0.15；这是因为当前强度来自连续随机生成，跨视窗精确相等提供了额外证据，但仍必须通过位置场形状和信息量检查。强度不完全一致时仍作为软因子，因为残差层表示有效贡献，不保证等于一个真实生成源的强度。

在本地恢复的 100 个测试窗口包上进行了开发集性质的接口诊断：其中 10 个场景具有重复视窗，共 22 个窗口、33 个跨视窗层对。以“连续强度完全一致”作为不完美的同源代理标签，共有 11 个正对；默认自适应规则接受 5 对，没有接受代理负对，对应代理 precision 100%、proxy recall 45.5%。该结果只说明当前规则偏保守并且在这批小样本上没有观察到误合并；强度相同不是真实源编号，因此不能把这些数字当作正式关联准确率。正式阈值仍需在独立开发场景上确定，并在不参与调参的测试场景上用真实源诊断验证。

该关联属于可执行启发式，不是已证明的真实源身份恢复。

已实现的首版接口：

- `rind_phase1.model.fuse_view_log_probabilities`：PyTorch 批量视窗证据融合；
- `rind_phase1.multiview.LayerField`：单视窗残差层位置场；
- `associate_layers`：无几何、无真实源编号的保守跨视窗关联；
- `fuse_track` / `fuse_associated_layers`：每条贡献轨迹的相关性折扣 log-evidence 融合。

### 18.2 模式 B：完整几何可见，作为 oracle/ablation

v6 不再替换 v4 energy head，而使用残差几何修正：

\[
E_{\mathrm{geo}}(s)
=E_{\mathrm{v4}}(M,w,s)
+\Delta E_{\mathrm{geometry}}(G,M,w,s).
\]

实现保证：

1. 从 v4 最佳 checkpoint 加载局部编码器、候选编码器、局部注意力和 energy head；
2. 几何修正头最后一层权重与偏置初始化为零；
3. 因而训练开始时 v6 对任意输入都与 v4 输出完全一致；
4. epoch 0 的 v4 验证结果直接作为可选最佳 checkpoint；
5. 前 8 个 epoch 冻结 v4，只训练几何分支；
6. 随后以 `1e-4` 微调 v4，以 `1e-3` 继续训练几何分支；
7. 几何 Transformer 从两层减为一层并使用 dropout 0.1；候选到几何的 cross-attention 从 1 个 head 增加为 4 个 head，而 v4 局部注意力仍保持 1 个 head；
8. batch size 从 768 降为 384，使 180 epochs 约对应 20,000 次更新，与 v4 的优化预算同量级。

因此，新几何模型不需要重新学习已经由 v4 掌握的局部定位关系。若几何没有提供泛化收益，模型选择可以保留 epoch 0，而不会被迫保存更差的几何模型。

### 18.3 “单一注意力”的准确含义

这里的“单一注意力”不是说整个模型只有一个 attention layer。v5 的障碍物 token 内部先经过两层 Transformer；问题在于每个候选位置读取完整几何时，只进行了一次候选 query 到全部障碍物 token 的 cross-attention：

\[
q(s)\longrightarrow
\operatorname{Attention}\bigl(q(s),K(G),V(G)\bigr).
\]

这一步得到一个固定维度的几何 context，随后直接与候选和局部响应特征拼接输出能量。模型没有显式构造：

- 候选源到视窗像素的射线；
- 射线与哪一个障碍物相交；
- 障碍物位于候选和响应边界之间的相对顺序；
- 候选移动后遮挡轮廓如何变化。

因此，一次 cross-attention 必须从原始 primitive 参数中隐式学习完整可见性算法。理论上网络有可能近似这一关系，但当前数据量、优化步数和结构没有让它可靠学成。v6 使用 4-head 候选—几何 cross-attention并用零初始化残差分支隔离风险；后续若继续提高 geometry oracle，应增加候选相对几何、局部 obstacle mask、SDF/occupancy pyramid 或候选—视窗射线采样特征。

- 无几何多视窗层关联、均匀/近均匀场拒绝、complete-linkage 和相关性折扣 log-evidence 融合核心；
- 100 窗口恢复包上的小规模关联接口诊断；
- 改进后的几何置乱诊断统计。

### 需要服务器正式运行验证

- v6 几何残差训练是否真正优于 v4；
- 几何置乱收益是否从接近零变为稳定正值；
- 多视窗关联阈值、强度软约束和视窗权重；
- 多视窗分布随窗口数量增加的收缩曲线。

### 尚未声称解决

- 无几何条件下从任意残差层集合唯一恢复真实源身份；
- 残差层跨视窗关联的理论唯一性；
- normalized max 汇总场的占用概率解释；
- 单视窗无几何模型达到 geometry oracle 的精度。

## 21. 十万场景单源学生结构升级

Phase2 最终仍复用单贡献定位器：多源窗口先做残差逐层解耦，每个二值层分别调用同一个 Phase1 学生。因此，新一轮训练没有把多层汇总场作为学生标签，而是扩大单贡献训练并更新局部响应编码器。

当前 `multiscale_boundary` 结构包含四项已经进入实际前向与反向传播的改动：

1. 对局部响应计算原始、2×、4×尺度 Sobel 特征。Sobel 使用复制边界，视窗裁剪边缘不会产生虚假的亮暗边界。
2. 边界、区域和全局信息分别由独立卷积分支编码。边界分支保留较高空间分辨率，区域分支在 1/4 尺度工作，全局分支在 1/8 尺度工作。
3. 注意力固定为 4 个边界头、2 个区域头、2 个全局头。三组拥有独立 Q/K/V，输出由候选相关门控融合。配置必须声明 `attention_heads=8`，模型不再创建无梯度的旧 attention 模块。
4. 候选查询编码候选相对窗口中心及四条窗口边的有符号距离。每组注意力进一步使用二维 RoPE，把候选和观察 token 的全场坐标放入 Q/K 旋转，使分数显式依赖候选与观察位置的相对位移，同时避免构造巨大的候选×像素×特征张量。

正式配置为 `hidden=384`、`fourier_frequencies=6`、8 个角色头，学生不读取隐藏全场障碍几何。训练目标仍是每个单贡献层在全场候选网格上的 Phase1 教师分布。旧 `full_training_h20_v2` 的合格 train 层可以追加为单贡献样本；旧 validation/test 不进入新版评估。

结构测试覆盖：三种尺度、恒定响应不产生窗口框伪边界、4/2/2 头分工、候选—token 相对位置的共同平移性质、分块与完整候选前向一致，以及所有新增分支获得有限非零梯度。模型质量仍需通过独立 validation/test 的 CE、KL、Dice、precision/recall、invalid mass 和源距离判断；结构检查本身不等同于效果提升。
