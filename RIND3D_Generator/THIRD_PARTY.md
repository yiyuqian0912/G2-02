# Dependency and source redistribution notes

The copied `rind3d`, canonical-geometry project and RINDRay project source belongs to the user's supplied projects. Their dataset/software license and citation decisions remain pending; this integration does not invent a grant. Original source headers are preserved. No system dependency source or precompiled library is committed.

External dependencies are obtained separately with their own licenses. CGAL has per-package GPL-3.0-or-later / LGPL-3.0-or-later terms and commercial alternatives; building or distributing an application requires checking the actual CGAL headers/packages used, rather than assuming a single permissive license. The CGAL source archive includes its license texts. GMP is dual licensed under LGPLv3+ or GPLv2+; its programs/tests have their own terms. Current FLINT uses LGPLv3+. Boost uses the Boost Software License; NumPy, Zstandard, pybind11, PyTorch, Z3 and optional Embree/NVIDIA components retain their respective upstream terms. Optional Embree/Vulkan backends are unrelated to the certified canonical visibility decisions.

Primary references: [CGAL license](https://www.cgal.org/license.html), [CGAL distribution license](https://github.com/CGAL/cgal/blob/main/Installation/LICENSE), [GMP copying](https://gmplib.org/manual/Copying), [FLINT introduction](https://flintlib.org/doc/introduction.html), [Boost license](https://www.boost.org/LICENSE_1_0.txt). Consult installed version notices for formal terms. No dependency is relicensed by this repository. Generated visibility data is distributed separately; the owner's explicit public-file sharing request does not settle an open-data license.
