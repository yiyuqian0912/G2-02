# Lite 观察分布、验证加速与逆源几何的证明边界

本轮是独立试验。`outputs/lite-v01-production` 的 100 个 READY_LITE 场景及原科学判定模块保持冻结。新 Core 仍使用 Lite v0.1：1024³ 响应和实体、256 个窗口、64/128/256 的 85/85/86 配额、唯一任意整数原点、真实源窗外、窗口内有亮和暗的自由体素。Core 只保留已通过双遍物理验证的真源；一个参考源不表示唯一解。

## 精确计数与观察分布

每个 16³ 子块保存亮自由和实体数量，暗自由数量由体积减去二者得到。1024³ 世界的粗前缀数组只有 65³×2 个 uint32，叶计数为 64³×2 个 uint16，共 3,245,576 字节。它不是世界分辨率的前缀数组。

任意非对齐窗口分成一个完整子块内核和至多六个互不重叠的边缘长方体。内核通过八个粗前缀顶点精确求和，边缘读取实际 packed bits，逐字节掩码、计数并检查 `response & solid == 0`。没有插值、浮点占据近似或探针估计。CRC32 的 slicing-by-eight 实现与原 RINDPack 的 IEEE CRC32 相同；原存储格式和原读写器未变。

自然路径直接调用原 D 选择器，选择完成后才附加私有计数。分层路径先用独立的 scrambled Sobol 原点流收集有界候选池，再按数据集累计比例缺额和软空间覆盖选择。混合分量按累计缺额实现 30% 自然、50% 十档均衡、20% 极端比例目标；这些是选择分量，不保证最后的总体直方图恰等于这个线性比例。自然分量也使用软覆盖，因此不声称是无偏抽样。场景缺少某档时，从池中其他档回填，记录欠额。样本池没有某档不等于证明这个场景不可能提供该档。独立均匀接受控制不参与选择。默认模型输入不增加比例、源或见证。

## 独立投影验证器 B 的化简

原 A 在闭参数区间上做线段裁剪；原 B 用有理 Fourier–Motzkin 消元构造闭阴影体。新试验 B2 仍只做投影体成员/区域判定，不调用 A 的线段裁剪。

对满维有界凸多面体 K、严格在 K 外的 p，阴影体满足 `S_p(K)=K+cone(K-p)`。它是满维闭凸多面体。一个二维支撑面来自：K 的前向面；经过 p 的原面；或 K 的轮廓边与该边沿源方向的射线。因而保留前向面、源共面面，以及源平面值异号的相邻真实面所对应的 FME 约束即可。相邻性由完整的精确三平面顶点枚举确定：两个真实面共享至少两个不同顶点。真实面的正面积用有理叉积核查；有界性、严格内部球和世界六面条件仍由原几何门禁证明。非面冗余约束不参与轮廓边构造。

这需要原完整顶点枚举的数学保证，不能把任意用户提交的不完整顶点列表当作依据。当前入口从 canonical 几何重新构造 `GeometryContext.geometry_proof()`，没有从未经验证的网格或近似凸包提取边。支持范围仍是已认证、严格包含在世界内的凸分量顶层并集。

新验证器复用源相关投影结构，并把父区域已证明的恒定响应或实体标签继承给子区域。子区域是父区域的子集，因此继承不增加未证明标签。未知仍细分或逐点精确判定。

### 区间热路径

规范化有理平面满足四个系数绝对值不超过 1，坐标在 `[0,1]`。系数转 binary64 的截断误差之和至多 `4·2^-52`；三次乘法误差至多 `3·2^-53`；三次相加和最后扩大区间的误差至多 `4·2^-50`，因为中间绝对值小于 8。因此用 `2^-46` 扩大计算出的两端，严格包住精确有理极值。这是推导出的算术误差界，不是几何容差，不会吞掉薄体或把切触变成未相交。

粗界跨零时仍执行原独立顺序的 nextafter 紧区间；未知点使用 GMP。系数不满足规范化前提时直接使用紧区间。运行时要求 binary64、RNE、关闭 FTZ/DAZ，编译禁止 fast-math 和 FMA 收缩。B2 不借用 A 的裁剪决定。二者仍共同依赖 canonical 平面、GMP 和几何结构，未被描述为完全独立软件栈。

## 非局部遮挡

对实际采样到的暗自由体素，以 GMP 求每个凸体在闭线段上的精确进入/退出参数，找到最早进入点并保留同时命中的分量。进入点严格在窗内、严格在窗外或在六个窗面上分别记录。窗采用半开采样区域，但所有面接触在因果审计中单独归类。

“首个命中在窗外”不保证阴影必须依赖窗外几何。更强的 `external_necessary` 还要求整条线段在闭窗口内完全没有障碍接触；此时删除窗外几何会使该点变亮。如果先命中窗外、随后又命中窗内，前者只说明首阻挡位置。边界接触不能冒充已证明的外部必要性。

每个被查询点的标签和首命中归属都是精确结果；窗口/家族比例来自空间八分区抽样并按该类体素数加权，是估计量而非穷尽结论。

## 逆源几何

接收点 x 与候选源 p 都必须在闭障碍外；候选还需满足原世界、净空、窗外和最小间距要求。闭线段可逆，所以对每个凸体：`[x,p]` 命中 K 当且仅当 `p ∈ C_x(K) = {x+λ(q-x): q∈K, λ≥1}`。这包括面、边和点切触。x 自由，故不会因 λ 的无穷极限错误包含 x。

多个障碍的暗约束是逆阴影体的并；亮约束是这个并的补。一个窗口的可行域是这些并/补的交，通常非凸且可能断开。试验对每个接收点保留完整凸并语义，没有把多障碍暗约束错误改成一个凸交集。

源空间盒只有在某个必要观测约束对盒内所有位置都不成立时才删除：亮观测却全盒被一个已认证阴影体覆盖；或暗观测却对所有障碍都证明全盒可见。并集共同覆盖却不能由单个分量证明时保留 UNKNOWN。源在实体内的全盒也可排除。预算耗尽时所有尚未检查的盒仍计入外覆盖。

稀疏约束的存活体积是完整逆集体积的保守上界，不是实际逆集体积；净空等未在全盒证明的条件只会使外覆盖更大。潜在可行盒不表示盒内每个源合法。本轮不声称得到认证内部盒、完整连通分支或精确直径。近似 SVD 和轮廓方向只提出候选，不构成解的证书。

三个实际 256³ 窗口得到了更强的、独立复查的上界。保留盒和删除盒用精确 dyadic 八叉前缀树重建，逐节点要求八个子节点齐全、无重叠、无遗漏；每个删除盒又用未改变的全 FME 逆阴影体重新认证。观测必须是原窗口内真实体素中心，标签还与原物理裁剪实现核对。证书绑定几何、政策、源字节、观测字节、窗口、间距和全部终端单元。

保留单元任意位置到真源的最大平方距离用 Fraction 精确求上界。三个上界均严格小于 `(32/1024)²`，因此完整窗口也不可能有达到参考间距的第二源：完整逆集必然包含在这些必要观测约束的外覆盖内。这个结论既不依赖均匀随机搜索没找到，也不是从候选数推断的。

同一批窗口还各自找到六个真源沿坐标轴正负 `2^-40` 的不同位置，完整原窗口经 A/B 独立验证后响应相同。它们只作研究见证，因为不满足参考间距而不写入数据集。此例直接区分了“坐标不唯一”和“没有符合参考间距的替代源”。没有据此声称已认证一个连续内部盒或精确解集体积。

有限二值体素一般提供不等式。即使观察到三个边界结构，也没有三个精确连续平面等式，更不能凭面数、矩阵秩、一次搜索只找到一个源来证明唯一性。必须分开讨论连续唯一性、可行域尺寸、是否存在相距至少 32/1024 的第二源，以及预算内找到多少见证。很近的等价扰动可能存在，却达不到参考源最小间距。

每个保留的额外源最终仍须通过完整原窗口的 A/B 两套物理重算。全局 64³ 砖缓存只比较与窗口相交的部分；窗外不同不能错误拒绝窗内等价源。稀疏约束、探针相同和外覆盖本身都不能发布源。

## 有界 Core 流水线

单个主进程拥有 GPU，CPU 子进程不创建 CUDA context。已渲染、已选窗的待验证场景有明确上界。软阈值 30 秒只在物理砖之间检查；未完成身份进入有界慢队列，至少每四次派发安排一次慢任务。不会为提速丢弃复杂场景。

硬看门狗作用于隔离进程，保留有自校验和的原子物理工作日志；一次调用中同一身份自动最多重试一次，显式 resume 是另记的会话，历史失败保留。超时记为不完整尝试，不是几何或物理拒绝。OS 实时时钟的默认终止信号不需要 Python GIL；Linux 父进程死亡信号及启动竞态检查，确保协调器被强杀后旧工作进程不能继续写日志。输出目录还有单生产者锁。

这个不可中断调用看门狗目前覆盖隔离 CPU 验证进程。GPU 生产者保留原 streaming 的预算与砖级检查点；它不能在驱动调用卡死时凭 Python 预算安全抢占 CUDA。此类故障仍需外部终止协调进程后显式 resume，不能宣称已实现驱动级自动恢复。现有强杀、坏日志和重新加载测试与真实试产中的失败计数分别报告。

完成双遍验证后才写真源引用和全部验收材料，通过标准及私有 DataLoader 后原子发布。额外源搜索不在 Core 发布路径；`rind3d enrich` 使用独立配置写外置、版本化、绑定原场景哈希的私有产物，以原子不可覆盖操作发布，默认读取时还会完整独立重查。既不延迟 Core，也不修改冻结 READY 场景。

旧完整 profile、旧 Lite 场景和原函数几何 READY 限制均不改变。
