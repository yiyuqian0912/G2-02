# Certified convex-polyhedron shadows: design and audit

The prototype is in `experiments/shadow_volumes`, outside production registration. It links the unchanged interval corner filter as a control, and uses GMP rationals and outward binary64 interval arithmetic. No default renderer, canonical codec, source distribution, sampler, loader or publication validator is replaced.

For `K={q:a_i·q≤b_i}`, an exterior source p, and `c_i=b_i−a_i·p`, a receiver x is blocked iff `x=p+λ(q−p)` for some q∈K, λ≥1. Substitution gives `a_i·(x−p)≤λc_i`. Positive c_i give lower bounds on λ, negative c_i upper bounds, and zero c_i a parameter-independent inequality. Since p is strictly outside K, at least one negative c_i exists. Existence of λ is equivalent to every upper bound being at least 1 and at least every lower bound. Thus the exact shadow is the intersection of:

1. `a_i·x≤b_i` for every c_i<0 (the front caps).
2. `a_i·(x−p)≤0` for every c_i=0.
3. `(c_j a_i−c_i a_j)·(x−p)≤0` for every c_i<0<c_j.

All inequalities are non-strict. Receiver endpoint contact, silhouette edge/vertex tangency and degeneracies remain included. Sources on/in obstacles are invalid in the dataset and rejected before construction. Sources on an extended face plane but outside the obstacle are supported by the zero-c_i case. The representation may contain many redundant planes; only exact positive-proportional duplicates are removed. Redundancy can make it slower than a minimal silhouette representation.

Canonical affine-box or convex-halfspace input coefficients are interpreted as exact binary64 dyadics. A rational Gauss–Jordan inverse transforms local planes into world planes, including the exact translation. Every stored native coefficient interval is checked against its GMP rational value. Dot products use explicit outward rounding with fast-math and FMA contraction disabled. A region is inside one shadow only when every plane's upper bound is ≤0; it is disjoint from that shadow only if some plane's lower bound is >0. Everything else is UNKNOWN. For a union, one obstacle can prove a whole region blocked; every obstacle must be proved disjoint to prove visibility. Different blockers at different corners are never combined into an invalid whole-region certificate.

The original corner certificate already uses convexity of this same shadow set. The new representation does not improve that theorem: it moves source-dependent work out of each brick, replaces repeated segment divisions with cached linear tests, and supports rotated boxes/general halfspaces. Both the original Python traversal and a native traversal using the unchanged corner filter are benchmark controls. This prevents calling a batching speedup a shadow-volume improvement.

The canonical backend regularizes intersection with the closed world Ω. The fast scope additionally requires a strict primitive-center interior witness in int(Ω), full-rank affine transforms, a canonical accepted bounded full-dimensional polyhedron, and top-level unions. Convexity plus that witness proves that regularization cannot delete a face-only world intersection. Unsupported cases, including a box merely touching Ω from outside, use the original evaluator. Removing that restriction requires an explicit topology proof, not a tolerance.

Hierarchical subdivision visits ambiguous regions down to point batches. Unproved point decisions call the existing canonical oracle; ABORTED and UNRESOLVED remain fatal. Geometry halfspaces/native representations are shared by content hash; each source rebuilds its own projected planes. A reused solid mask is read only after its geometry/source/policy-bound RINDPack identity and file hash match. Mask reads are locked and brick-cache bounded. The native reuse path omits solid predicates and replaces its temporary mask with those exact stored values before returning. The current source-bound file headers still require a separately serialized mask for each pair; no storage format is silently changed.

Independent all-voxel checks use a different algorithm: parametric segment clipping against the canonical convex halfspaces, with interval separation and GMP fallback for exact comparisons. This implementation does not consume projected shadow planes. It shares codec plane extraction and interval primitives, so canonical CGAL point/ray boundary checks and original renderer full-field controls remain necessary. An incomplete CGAL-only replay is recorded as incomplete, not called an exhaustive canonical comparison. New families remain experimental even when finite sampled-field checks pass.

Each experimental source-response record has a unique source ID derived from geometry hash and exact source bytes. Every source sharing a geometry uses a geometry-hash split group. This policy is implemented in the experiment manifests; production's older scene-ID split policy is not silently claimed to support geometry reuse.
