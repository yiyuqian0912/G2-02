# Certified field acceleration: proof obligations and limits

The new adapter is scoped to sampled-field generation. `geometry.py`, the canonical continuous codecs, the existing exact fallback, closed-segment semantics, and `ready_capable` are unchanged. Supported acceleration expressions are one cosine leaf in a top-level union with positive diagonal affine boxes/balls. Other expressions use the original evaluator. No mesh or sampled occupancy approximation defines geometry.

**Cell signs.** At each closed dyadic box, Arb encloses the exact canonical score `bias + Σ a cos(w·x+phase)`. Input binary64 coefficients/coordinates retain their exact dyadic interpretation. A strictly positive enclosure proves that the entire closed cell is inside the solid. A strictly negative enclosure proves the entire cell is free. Otherwise the node is subdivided or retained as UNKNOWN. Node/depth budgets can only lose acceleration, never create a label. This removes expensive optional proofs of MIXED, which cannot fill either output field.

**Point bases.** For resolution N, Arb encloses sine and cosine of each exact per-axis affine angle at `(i+0.5)/N`. Phase is included on one axis. Each binary64 endpoint is checked as an exact Fraction against Arb's exact endpoint; conversion is adjusted outward if necessary. The native evaluator uses the trigonometric addition identity with outward-rounded operations. It accepts only exact sampled centers; arbitrary points use cell proofs or the original oracle. Nonconstant zero-containing score intervals remain unknown. Canonically cancelled constant zero fields stay empty. No interpolation or float32 operation is used.

**Rays and shadows.** Interval slab tests may skip a cell only on proved disjointness. A ray may be labelled blocked on a proved intersection with a certified-solid closed cell. It may be labelled visible only if every potentially intersected cell is certified free. Touching UNKNOWN or an ambiguous solid cell cannot prove visibility. To certify a whole receiver box as shadowed, all eight corner rays must hit the **same** convex certified interior box; its shadow is convex and therefore covers the receiver box. Different occluders at different corners are insufficient. Whole-box visibility uses a conservative enclosure of all source-to-box segments.

**Residual function rays.** The optional Arb proof encloses the same exact function along `s+t*(p-s)`, using affine phases `A_j+B_j*t`. Strict positivity on any subinterval or at a midpoint proves HIT; strictly negative bounds covering the entire closed parameter interval prove MISS. Float dyadic subdivision points partition the interval without gaps; inability to form a strict midpoint yields no proof. The trial uses 64-bit Arb bounds and a declared subdivision limit no larger than the canonical per-query limit. Inconclusive trials call the unmodified canonical predicate with its original precision ladder and full declared allowance. Equality, tangency or numerical uncertainty is never resolved by a tolerance.

**Union composition and failures.** A certified HIT on any branch proves obstruction. MISS requires proofs on every branch. An algebraic branch is omitted from an expensive composite query only after the unchanged primitive filter proves its decision. Unproved algebraic cases use the original composite oracle. The original function predicate handles unresolved residual function rays. Mandatory ABORTED/UNRESOLVED results still fail generation. Optional proof failure merely causes more exact work. Functional queries involving domain-face endpoints use the original path; this accelerator does not implement missing Ω-face topology proofs.

**Caching and concurrency.** Spatial cells and trig bases depend only on lossless geometry, resolution and proof settings. Source-angle caches compare exact source coordinates. Membership caching compares actual array contents and retains at most 4096 points per worker; it never caches source-dependent visibility without a source key. The original oracle lock protects Arb precision contexts and exact fallback. Native immutable tree/basis queries can release the GIL. Streaming queues, brick ordering policy, writer, format and index are unchanged.

**Validation scope.** Completed old/new fields are compared at every response and solid bit. When the unchanged mixed CGAL facade cannot finish, an explicitly separate reference audit uses its original certified primitive filter plus original scalar Arb predicates; it does not reuse the new tree, bases or coupled-ray proof. Large functional full-ray reference audits that do not complete are not described as full comparisons. Targeted tests cover thin subcell solids, exact boundary contacts, tangency/nextafter, domain faces, unknown handling and mutation-safe caches. A bounded 1024³ performance pilot requires the recorded smaller-field gate; it is not a publication certificate.

**READY remains closed for functions.** Finite center samples do not complete the canonical backend's full relative Ω-face topology, boundary incidence/degeneracy, transcendental distance/clearance witnesses, capability registration or generator acceptance integration. Those require independent implementation and verification. A faster or fully generated field does not turn `ready_capable=False` into true and does not certify continuously many points or inverse solutions.
