# RIND3D — 3D Physical Reasoning Dataset dataset card

RIND3D studies point-source visibility and inverse reasoning from partial binary observations. It contains synthetic static scenes; it does not model radiance, reflections, attenuation, materials, sensor noise, multiple scattering, or real photographs. One source has unit binary visibility strength. The scientific geometry is continuous, while supervision is a finite 1024³ voxel-center sample.

The first Core distribution uses only top-level unions of certified, strictly world-contained convex components. It includes all nine families listed in the README with equal cyclic allocation. Objects vary in position, orientation, size, thickness, count and spatial organization. The immutable manifest records the generator version and parameter distributions, including obstacle count ranges, quaternion orientations, thin-slab thickness distribution and polyhedron plane choices. Geometry family balance does not imply identical complexity or difficulty across families.

Sources are sampled uniformly from the world and accepted by the existing FREE-space and clearance checks. Source/geometry randomness is independently derived from a private master seed. If complete stored response data gives a sufficient, independently checked proof that no informative windows can satisfy the existing spatial coverage gate, the source is rejected and resampled while retaining its geometry. This conditions the source distribution on observation feasibility and is recorded in production reports. Proposal budget exhaustion without a proof is incomplete work, not a physical rejection. The frozen configuration bounds source-field trials and window proposals; there is no speed-based geometry filtering.

Every window contains positive and negative FREE observations. Mixed sampling targets broader lit/free coverage using ten bins and natural/uniform/extreme soft components. Its proposal pool, coverage and overlap objectives introduce selection bias. Ratios exactly zero and one are invalid. A scene is not forced to supply unavailable bins. The production report contains realized ratio-bin counts and deficits; the manifest states the frozen target policy. Do not substitute targets for measured distributions. Natural sampling is a separate baseline, not an identical distribution.

Window overlap is allowed. Multiple windows from one scene are correlated and must never be treated as independent scenes for train/test splitting. Splits use the canonical geometry ID with the documented stable hash protocol and approximately 80/10/10 proportions, not exact per-release split quotas. Actual counts are in the manifest. Additional sources sharing a geometry must preserve that geometry's split.

The full response field and canonical geometry are public under the full-field training policy. This can reveal more information than a local-observation model should receive. The reader preserves the existing full-geometry interface; users studying strictly local inputs must explicitly restrict it. Hidden source labels are withheld as serialized private data, not protected against scientific inference. Restricted evaluation with hidden full fields requires a different explicitly versioned artifact policy.

Each private Core window has one true-source reference that passed full-window verification and independent rechecking. A single reference is a witness of compatibility, not evidence of uniqueness. Sparse probes, approximate cones, or sampled feasible volumes are not full-window equivalence proofs. Optional ambiguity enrichment remains outside Core publication.

Numerical truth uses canonical binary64 inputs interpreted exactly by certified predicates. Closed-segment endpoint contact and tangency block light. Complete response and solid fields, exact stored-window eligibility, source clearance, geometry acceptance and two independent physical verification implementations are mandatory. Unsupported functional/CSG families retain their publication restrictions. Integrity hashes are not substitutes for physical verification; public readers check integrity while restricted production retains physical evidence.

Spatial coverage, nonlocal external-occlusion evidence and production performance are measured in the accompanying release report when available. External causal occlusion requires certified blocker relationships; long rays alone do not establish it. Measurements from earlier 100/300-scene datasets must not be presented as measurements of this snapshot. See the actual report and manifest rather than assuming all scenes share their statistics.

Campaigns have deterministic IDs and attempt seeds independent of cumulative target and worker order. Configuration/build identities freeze before production. Committed scientific files never change. Full releases and deltas carry immutable parent identities and checksums. This package is suitable for method development and controlled synthetic evaluation, not a claim of real-world generalization.

License and citation authors are pending. No sensitive personal information is intentionally collected; the withheld labels are synthetic scientific supervision. Known operational coverage is Linux x86_64/Python 3.12. Other environments require validation. No online upload or open-data license is implied.
