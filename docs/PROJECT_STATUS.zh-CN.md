# 项目状态与已确认结果

更新日期：2026-10-28。这里区分已经跑完的实验和已经交付但尚未确认完成的流程。

## 目标和主线

学生在未知全场障碍几何的条件下，从局部响应推断驱动源；未来结合多个视窗逐步缩小位置不确定性。物理教师使用隐藏几何提供监督，真实源位置只用于评价。

已实现单贡献位置概率预测，以及多源局部响应的有效贡献分层。当前主线是先把学生分层能力训练好，再连接Phase1定位器；完整多源定位和动态扩窗闭环尚未得到系统验证。

## Phase1：单贡献定位

- 实际训练80,343条记录：37,072条单源记录，加43,271条已完成检查的多源残差层。验证4,530条，测试4,714条。
- 模型约20,030,020参数，隐藏维度384，6级Fourier坐标，多尺度边界/区域/全局分支，4/2/2注意力头分工和候选相对几何。
- 基础评估：最佳epoch18，Test CE=7.316051。
- 独立综合评估口径：核心区域Dice@75=0.551211、Recall@75=0.780678、Precision@75=0.489333。它们衡量位置概率核心区域，不是Phase2的局部响应掩码。
- 全场几何输入消融曾运行；该已跑版本没有改善主要指标。不能据此认定几何信息没有价值。

历史训练与优化细节见 [Phase1训练报告](../Phase1_Single_Source_Single_Intensity/docs/PHASE1_100K_MODEL_OPTIMIZATION_REPORT.zh-CN.md)。该报告部分段落截至epoch36；本页结果来自后续回收的评估摘要，不把不同统计口径混合成同一指标。

## Phase2：有效贡献解耦

2万窗口版本已完成训练，使用20000/2000/2000个实际train/validation/test窗口，最佳epoch37。

| 测试指标 | 数值 | 含义 |
|---|---:|---|
| 软掩码Dice | 0.890195 | 匹配后的有效层掩码相似度 |
| 有效层数准确率 | 0.799500 | 有效贡献数预测完全正确的比例 |
| 层数MAE | 0.269500 | 平均层数绝对误差 |
| 总响应重建绝对MAE | 0.017727 | 各预测贡献叠加与观测的差异 |
| 逐层残差误差 | 0.026926 | 沿教师剥离顺序的残差差异 |

该摘要不包含完整硬掩码IoU/强度MAE报告；`intensity`字段是训练损失，不能当作强度MAE。有效层数不等于生成场景的真实源数，软Dice不等于整窗解耦成功率。

## 尚需完成

1. 回收10万窗口实验结果，按有效层数和视窗大小比较固定测试集表现。
2. 实现严格整窗成功率：模型实际启用槽位的数量正确，每层掩码和强度同时达到阈值。当前尚未实现该联合指标，也未确认达到90%。
3. 验证有效层的单源物理可实现性；算术重建正确不是充分条件。
4. 用学生预测的掩码连接Phase1，评估真正端到端多源定位，而不是oracle掩码定位。
5. 推进集合训练、多视窗约束融合与动态扩窗收敛实验。

暂定项目验收目标：层数准确率至少90%，逐层IoU至少90%/Dice约95%，强度总相对误差不超过10%，重建相对L1不超过5%，最终争取严格整窗成功率至少90%。这些是待落实的项目目标，不是已取得的结果。
