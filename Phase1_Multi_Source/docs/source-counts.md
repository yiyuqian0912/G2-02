# 是否先保留随机 1–4 个源？

建议先保留 **1–4 个源作为主数据集**，完成可复现基线，再单独生成 **5–8 个源的压力测试集**。这是分阶段实验建议，不是“最多四个源才正确”的物理结论。

场景数基本平衡，但源多时四分树通常产生更多窗口。因此均匀抽观测不会平衡源数：四源样本约占 37%，单源约占 12%。可按场景或源数平衡抽样，至少分别报告 K 和窗口尺寸下的结果。

## 为什么先用这个范围？

1. 一源到多源同时覆盖：重叠强度、互相遮挡、多解、源组合之间的相关性。
2. 固定 K 时，每个源有两个坐标加一个强度，共 3K 个连续参数。联合网格搜索的成本随维度迅速增长，先把 K=1–4 的目标定义和可观测性弄清楚更容易定位问题。
3. 增加 K 可能让多个源的可见区域互相补足，也可能引入更多不可辨识组合；不能断言源越多就一定越难或越容易。需要实际分层评价。

## 比“最多四个”更需要明确的事情

- **源数是否已知？** 当前学生输入不包含真实 K。若后来把 K 提供给学生，是另一种实验，需要明确标注。
- **源数能否从局部响应唯一恢复？** 不能普遍保证。完全不可见的源不影响这个窗口；同位置源可拆分或合并强度。当前参考组已经示范 K 与 K+1 的等价组合。
- **弱源有多少？** 当前约 5.05% 的源强度低于 0.05；最低约 `2.24e-5`。不要在读取时悄悄删掉弱源或改强度分布。若研究弱源辨识，分别报告强度区间。
- **源顺序是否有意义？** 行顺序只是存储顺序。物理源组合应对排列不敏感；这类集合表示可参考 [Deep Sets 原论文](https://arxiv.org/abs/1703.06114)。重复同一集合的排列不能当作不同物理解加权。
- **是否允许零源？** 零源适合作为另一个负例实验；它改变“至少一个源”的生成假设，且全零观测也可能来自被完全遮挡的非零源。建议单列，先不混入当前任务。

多源版中 K=1 的强度也是随机值，不能与强度固定为 1 的单源数据混为同一种分布。先分别验证：已知 K、未知 K，以及训练 K=1–4/测试 K=5–8。这样才能判断模型是否真的学到了可扩展的源组合兼容性。
