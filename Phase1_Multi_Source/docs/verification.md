## “窗口外”和不同尺寸教师的结论

主任务明确为窗口外源的固定窗口响应兼容性。多源物理评价要求每个源在世界内、窗口外、障碍物外，**不限制在 quadtree 父节点内**。quadtree 仍用于数据窗口生成。

当前分支的单源研究文件是早期占位版本。完整单源均匀教师实现保存在本地提交 `e7992e8`（`feat/model-yushu`，也在 integration 历史中）。此次独立导出该提交的教师代码验证，未把该分支模型/训练代码迁移到多源目录：22 项教师测试、真实数据上的全部六种窗口尺寸、60 个单源参考位置的精确重渲染均通过。检查用世界候选间距 128、温度 .05，只是快速验证设置，不是正式研究默认值。

## 多源联合教师（同分支新增）

实现按明确源数先验分层的联合抽样：均匀位置网格、独立随机强度、源排列去重、基础权重聚合、整组响应代价与稳定教师概率。每个源都在窗口外，不限制 quadtree 父节点。固定源数和未知源数均可明确指定。未读取真值源数／参数或参考解来提出候选。

| 检查 | 结果 |
|---|---|
| 25 项单元测试 | 原有 9 项数据测试及 16 项联合教师测试通过 |
| 几何／支持语义 | 世界与窗口边界、均匀网格顺序、几何有效性、排列去重、同位置源、显式数量先验通过 |
| 概率与失败行为 | 无效候选为零、概率和为一、极小温度／巨大代价稳定、无有效候选失败、预算不足拒绝归一化通过 |
| 标签隔离 | 真值／参考／分源通道 API 禁用的包装数据集仍能生成教师 |
| 实际数据教师 | 场景 0、11、2、1，各取六种尺寸，共 24 个观测、6144 组联合候选通过 |
| 直接物理核对 | 每个观测抽查第一组、最后一组和最高概率组，缓存代价与整组直接渲染最大差为 0 |
| 参考组检查 | 138 组另行重渲染，最大代价为 0，未注入候选集合 |
| 可移植记录 | 压缩 NPZ、JSON 元数据、无 pickle 读取、参数／代价／概率顺序对应通过 |
| 安装与出图 | 新命令入口、diagnostics 可选依赖、uv 锁文件和真实诊断图验证通过 |

实测设置：位置间距 128，K 支持 1–4、各先验 .25，每个 K 抽 64 组，温度 .05、种子 20260923。全部观测使用相同的声明源数策略；真实 K 仅用于选取验证覆盖，未传给教师作为标签。每个窗口 256 组候选只需 42–64 个不同位置的单位可见性计算。这些是流程检查参数，不是正式实验默认值。

另生成 scene 1 / view 13 的 4096 组演示，间距 64、每个 K 抽 1024 组，其他参数相同。实际使用 244 个位置的可见性计算，位压缩缓存约 488 KiB，整份教师 NPZ 约 174 KiB。最低平均强度误差为 .0907467，联合熵 6.0563 nats，有效候选数约 125.8。六组参考组合仍为零代价；采样组合未命中零代价解，因此不能声称穷举或精确覆盖联合逆解。实例说明见 `teacher.md`；可重跑的记录、JSON 和图像位于 `outputs/teachers/example-scene1-view13.*`，检查报告位于 `outputs/reports/joint-teacher-check.json`，输出不纳入 Git。

二维存在概率和最小代价图均明确标为联合分布的投影。没有把二维连通区域数冒充高维联合逆解的连通区域数。学生模型／训练代码未修改，任务分工表未修改。
