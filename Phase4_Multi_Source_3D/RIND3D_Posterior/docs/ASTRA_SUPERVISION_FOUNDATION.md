# From finite observations to certified Student targets

**Decision.** The frozen CPU issuer and the exact sparse training reader qualify for bounded single-host research batches with authenticated inputs, immutable issued artifacts and the qualified runtime. The mathematical result is conditional on correct execution of the reviewed primitives. No verifier replay or statistical fallback is part of this result. The historical 807-channel population is the qualification cohort. The 100K population has not been issued.

## A three-transition proof

Fix one authenticated task for the whole run. In the unit world, let F be the legal continuous source positions reproducing every observed FREE receiver in the window under canonical closed-segment visibility. Legality includes the world, exclusion of the closed window and distance strictly greater than 2⁻²⁶ from each obstacle. The observed classes and canonical convex-union geometry are fixed. Neither a private source coordinate nor a fitted continuous interface is evidence. The output cells partition the world in XYZ order. Use half-open ownership, with exterior faces assigned arbitrarily for volume. All geometric set inclusions below are up to three-dimensional Lebesgue null sets. This permits a common split face to have two closed representations. It does **not** permit ignoring contact in the predicate at an observed receiver.

The proof needs three invariants.

1. **Ownership.** Live pieces, settled feasible interiors S and discarded interiors partition the original cube almost everywhere. S is contained in F, and F is contained in S union the live pieces. Each live piece owns an immutable description of its outstanding obligations. Every omitted FREE receiver condition holds throughout its surviving piece. Clearance may remain pending.
2. **Accounting.** In common volume units, for each cell i, lower and upper integer credits satisfy ℓᵢ ≤ volume(S ∩ Cᵢ) ≤ hᵢ. A live piece of volume v has charge ceil(v). Only when the entire piece is in cell i can its charge be removed from the outside-i sum. Live and settled credits refer to disjoint interiors. Upper credits may overestimate.
3. **Publication.** A checkpoint binds the same task to immutable, exactly normalized probability bytes and their own upper bound. Only a healthy kernel can release an eligible checkpoint. An attempt without an authorized completed receipt supplies no training target.

**Initial state.** One live unit cube, all FREE receivers and legality outstanding, zero settled and discarded volume. The invariants hold.

**REFINE.** Replace an owned live piece by children with disjoint interiors. Together with any part proved impossible, they cover the parent. A child inherits all outstanding conditions except those proved on the child. A blocker union assigns ownership by subtracting earlier blockers. Removing a branch requires a proof that it cannot contain feasible volume. A split cap, an exhausted search or an inconclusive bound gives no such proof. Replacing charges by the children's ceilings still upper-bounds their volumes. Rounding can increase that sum without duplicating physical ownership.

**SETTLE.** Partition an owned live piece into proved-feasible parts, proved-impossible parts and a residual. Every feasible part must meet every observation and legality condition. For each feasible part, integrate against the disjoint cells and add directed floors and ceilings. Retain each residual as live, including unresolved clearance shells. Atomic removal of the old handle forbids settling it twice. REFINE and SETTLE may share a single atomic commit. Failure before publication of the replacement leaves the old state authoritative. Scientific guard failures taint the run.

**RELEASE.** Write U for the sum of all live ceilings and uᵢ for the ceilings certified wholly in i. Then bᵢ = Σⱼ≠ᵢ hⱼ + U − uᵢ bounds all feasible volume outside i. With ℓᵢ > 0 the total feasible volume is positive. Monotonicity of x/(x+y) for nonnegative inside and outside volumes gives qᵢ ≥ aᵢ = ℓᵢ/(ℓᵢ+bᵢ). Set aᵢ=0 when ℓᵢ=0. For the probabilities p actually decoded from the wire,

    TV(p,q) = 1 − Σᵢ min(pᵢ,qᵢ) ≤ 1 − Σᵢ min(pᵢ,aᵢ).

The implementation rounds the lower overlaps **down** before subtraction, so the reported rational bound rounds outward. Positive lower mass is mandatory. A zero-volume F has no normalized volume target. A zero in p certifies no impossibility at that cell.

**Conclusion — MATHEMATICALLY PROVEN.** Induction on committed transitions gives the three invariants after any finite execution. An eligible earlier checkpoint remains a statement about the same F even if later work is unproductive. Every healthy release therefore satisfies TV(decoded wire,q) ≤ ε ≤ 1/20. The proof needs neither an exhaustive feasible set nor a particular exploration order, runtime or number of support cells. The frozen application provides partial correctness, with abstention.

### Proof status and trusted base

- **MACHINE-CHECKED.** 32 existing arithmetic implications cover intersection signs, homogeneous orientations, envelope directions, signed ranges, clearance, TV and accounting, including the truncated simplex in one dimension. Three additional Z3 checks cover the 64-bit digit identity, top digit bound and safety of chunked summation. The SMT model does not translate or verify Python, Numba, the compiler or all split control flow.
- **IMPLEMENTATION-REVIEWED.** The source mapping above, exact split/topology argument, positive rational rescaling, ownership transitions, receiver subset inheritance, analytic cell formula, multi-facet fallback and seal/reader paths. Exact Python int/Fraction operations, pre-screened int64 Numba operations and binary64 input interpretation have separate obligations. Python reflection or malicious same-process code can bypass a Python API. Qualification applies to the reviewed immutable program.
- **EXACT-DIFFERENTIAL-TESTED.** Existing independent rational vertex/halfspace volumes and the archived 14 exact posteriors, now compared to the actual training weights by integer address and exact fractions. Permanent adversaries cover malformed split caps, wrong or double credit, noncanonical GMP rationals in the optional comparison helper, signed overflow, forged wires and exact normalization. The 214-cell fixture is included.
- **EMPIRICALLY TESTED.** All 807 archived issues, multicell cases, thin slabs, worker loss/recovery, duplicate issuance refusal, CPU tensor conversion and the Student loss integration. The two archived legacy Tau-pencil violations remain negative controls. Agreement with an older labeler never earns credit.
- **ASSUMED.** Correct CPython, arbitrary-precision arithmetic, NumPy, SciPy, LLVM/Numba code generation, declared integer overflow guards, native binary64, zstd, canonical codec, hashing and trusted local OS/filesystem. Qhull or floating anchors may suggest work, with physical acceptance checked in the trusted path. Native GMP grid-credit code is a differential control. The issued profile selects Python integer/Fraction grid credit. Torch/NumPy CPU semantics and unmodified buffers until consumption are additional Student-side assumptions. Upstream world/window sampling provenance and authentic independent digest distribution remain external.
- **OPEN.** End-to-end machine verification, malicious runtime resistance, power-loss/multi-host qualification, accelerator-side target transformations and other physical families. A new CPU/toolchain or a changed geometry codec requires requalification. The independent index identifies bytes but cannot establish an honest scientific issuer by itself.

The runtime manifest fingerprints the numerical files, native binaries and wheel records. Two additional dependencies of the scientific handoff deserve explicit pins: the actually imported `rind.identity` (array/field decoding) and `assurance/campaign.py` (worker, release and receipts). The separate preflight now checks both plus the **entire** approved numerical build. It runs outside the solver and leaves the frozen artifact identity intact.
