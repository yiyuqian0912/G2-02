# Mixed-interface patch pilot, revision 1

Base `18465250870cbdb7a540be4537bb96efb08b122c`. Research only. Read the existing 54-task `cmp_v3/tasks.json` and Tau-pencil records. Use one CPU process. All tasks enter, including early exits. For each task take up to four distinct aligned 8³ patches with an internal direct FREE–FREE interface, spaced by quartiles of lexicographic XYZ patch order (midpoint rank). This samples patches, with no guarantee of sampling interface area uniformly. Never load source coordinates. No geometry/source fitting or tuning.

For every patch test three closed source boxes: one seed-keyed uniform 1/128 box, the highest lower-mass archived Tau-pencil 1/128 cell (ties: smallest index), and its 1/16 ancestor. The last two are deliberately privileged feasibility diagnostics. They cannot validate an unassisted search strategy. Record every result, including ambiguous or constant charts. Keep the original solver and archived posteriors intact.

Use unbounded integer predicates on canonical rational planes. Certify absence of all other bodies and that across the source box and receiver patch a single remaining determinant decides the finite observations. Compare the observed strict/closed extrema, fallback rate, retained source-box volume for applicable patches, and original local pure-block counts. Verify selected real charts against independently coded exact closed-segment clipping at two source positions, all FREE patch receivers, first certified 1/128 reference patch per task. Compare cached and full-patch tests on a common fixed set of subcell queries. All preparation charged, mathematical support reduction and end-to-end speed measured separately. No production labelling benchmark in this first pilot.

## Exploratory follow-up after the patch pilot

Use the same 54 highest-lower-mass source cells. Test the *entire* observed window inside that one cell, with at most two octree subdivisions on the receiver side (at most 73 boxes). Keep exact proofs of constant labels or single pencils; SOLID receivers have no response constraint. On an unresolved patch abstain from declaring exact mass. Cap exact volume integration at eight hinges.
