**Status key.** M = MATHEMATICALLY PROVEN in the stated model. Z = MACHINE-CHECKED arithmetic implication, under the hypotheses of the named Z3 script. R = IMPLEMENTATION-REVIEWED. D = EXACT-DIFFERENTIAL-TESTED on bounded fixtures. E = EMPIRICALLY TESTED. A = ASSUMED. O = OPEN. Multiple entries on one row refer to different levels of assurance. No row marked Z implies verification of the Python control flow, generated LLVM or executable.

**Outstanding implementation trust.** The state transition model does not verify CPython reference behavior, file parsers, binary64 routines, LLVM lowering, Numba index semantics, allocator/kernel behavior, libm or the operating system. Only exact-validated outputs of floating proposers enter geometry decisions. SHA-256 digests identify bytes; neither wheel RECORD metadata nor Git alone proves the mathematical correctness of a dependency. Corrupted interpreter/OS, hostile same-user writes, malicious containers designed to exhaust an unrestricted coordinator, and distributed multi-host ownership are outside this tested operating boundary. The two archived Tau-pencil defects are negative controls; agreement with legacy outputs is never an authorization to issue.
