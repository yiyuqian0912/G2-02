# RIND Phase I：项目分工与文件目标

[English](README.md) | 中文

**项目目标：根据局部响应和窗口位置，预测源在二维空间中的可能位置分布，保留多解与不确定性。**

物理教师通过 RIND 重渲染判断候选位置能否解释观测；学生学习这种判断，预测时不再逐候选重渲染。项目只保留 **7 个核心研究文件＋1 个验证文件**，每个文件对应一个完整任务。

**当前状态：**目录、配置和职责占位文件已建立，研究功能尚未实现。原始 RIND 代码和数据仍需接入。文件存在不代表功能完成。

## 1. 与 proposal 的对应关系

沿用 proposal 的单源、固定强度、连续二维遮挡环境，以及按 `scene_id` 划分数据的要求。不引入距离衰减、反射、噪声或材料差异。

根据后续讨论，更新两处任务定义：

- **观察窗口改为动态四分树**：含源区域四等分，无源区域停止分割；最小为 16 × 16，仍含源的最小叶节点不作为观测。
- **学生条件输入为响应＋窗口信息**：窗口信息包含位置和大小 `(x, y, side)`。候选源坐标是模型需要评价的查询位置。

| Proposal 内容 | 对应文件 | 必须完成的目标 |
|---|---|---|
| §1 问题定义与数据划分 | `data.py` | 新单源数据、正确观察窗口、无场景泄漏的划分 |
| §2 正向重渲染与逆向监督 | `physics.py` | 给定候选源，生成可与真实观测比较的响应 |
| §3 物理监督信号 | `physics.py` | 边界加权响应代价，以及可选的边界几何代价 |
| §4.1 物理代价到监督分布 | `teacher.py` | 保留多个合理候选的教师分布 |
| §4.2 条件能量模型与拟合 | `model.py`、`train.py` | 学生候选评分与教师分布拟合 |
| §4.3 Fourier 坐标表示 | `model.py` | 支持连续候选坐标及其细粒度变化 |
| §5 自适应候选搜索 | `search.py` | 从粗到细减少物理评价成本，并检查可行区域是否遗漏 |
| §6 评估目标 | `evaluate.py` | 分布一致性、不确定性、未见场景泛化和边界项消融 |
| §7 整体方法 | `checks.py` | 验证数据、教师、学生和评估能够正确衔接 |

自适应搜索是完整方案的一部分：先跑通均匀候选基线，再完成自适应搜索对比。边界项可以关闭，但需要比较加入前后的效果。Fourier 特征用于学生模型，不改变物理渲染。

## 3. 每个文件需要完成什么

### 3.1 `data.py`：提供符合 Phase I 定义的数据

**接收：**原始 RIND 项目位置、场景数量、固定强度、随机种子与数据划分设置。

**需要完成：**

1. 接入原始 RIND 生成能力，创建新的单源、固定强度数据，不覆盖旧数据。
2. 提供动态四分树产生的无源窗口；若 RIND 已正确提供窗口，直接读取并验证。
3. 按场景划分训练集、验证集和测试集，同一场景的所有窗口进入同一集合。
4. 向其他文件提供统一样本，保留不同窗口大小和世界坐标含义。

**交付：**`data/raw/` 中的新数据、`data/splits/` 中的场景名单，以及可读取的观测样本。每个样本至少含 `scene_id`、`view_id`、`response` 和 `window=(x,y,side)`；真实源与场景几何仅供监督和评价使用。

**完成目标：**样本没有源落入观察窗口，划分没有场景重叠，任意样本可追溯到原场景。1024 场景按单源规则分割至 16 时，应得到 18 个无源窗口，作为数据检查依据。

### 3.2 `physics.py`：评价一个候选源是否解释了观测

**接收：**原场景、真实观测、窗口信息、候选源坐标及固定强度。

**需要完成：**

1. 在原场景中放置候选源，重渲染同一个观察窗口，得到候选响应。
2. 计算边界加权响应误差 `Lresp`。权重只由真实观测边界决定；没有有效边界时使用均匀权重。
3. 提供可选的对称边界距离 `Ledge`，评价边界的位置偏移、遗漏和额外出现。
4. 输出组合代价 `C = αLresp + βLedge`，支持 `β=0` 的响应项基线。

**交付：**候选响应、分项代价和最终物理代价，供 `search.py` 和 `teacher.py` 使用。

**完成目标：**真实源能重现原观测；各候选使用一致的评价标准；没有边界或边界缺失时有明确结果。此文件输出代价，不构造概率分布，也不训练模型。

### 3.3 `search.py`：找到值得物理评价的候选位置

**接收：**候选源允许范围、窗口信息、物理评价能力和候选计算预算。

**需要完成：**

1. 提供均匀候选集，作为初始基线和小规模参考。
2. 完成由粗到细的搜索：先覆盖源空间，用响应一致性筛选，再细化低代价或按明确规则判断为不确定的区域。
3. 使用边界增强时，对最终候选补充所需评价；交给教师的最终代价必须含义一致。
4. 记录候选数量、物理评价次数和必要的空间权重；检查是否漏掉分离的合理区域。

**交付：**候选坐标、候选有效性、已获得的物理代价及搜索记录。候选在世界内、观测窗口外，物理教师还需排除障碍物内部的位置。

**完成目标：**自适应搜索相对均匀参考减少计算，并提供保留合理解区域的证据。它改变教师构造成本，不改变学生输入或模型结构。仅有自适应设计说明不算最终完成。

### 3.4 `teacher.py`：把物理代价转为监督分布

**接收：**观测标识、候选坐标、最终物理代价、温度和必要的空间权重。

**需要完成：**

1. 组织 `search.py` 与 `physics.py` 为观测构造候选评价，复用已计算的结果。
2. 按 proposal 将代价转为软分布：等权候选时 `qᵢ ∝ exp(−Cᵢ/τ)`。
3. 保留多个合理位置的概率，不只保存代价最低的一个坐标。
4. 保存完整监督记录，确保训练时知道每个概率对应哪个候选。

**交付：**`outputs/teachers/` 中的监督文件，包含样本标识、候选坐标、物理代价、教师概率及相关设置。

**完成目标：**分布归一化正确，可追溯到物理评价；候选位置、顺序和权重不会在交接中丢失。非均匀采样时明确概率代表候选集合内的质量还是空间面积，教师和学生使用同一约定。概率总和为 1 不代表一定存在好的解释，因此同时保留原始代价。

### 3.5 `model.py`：从观测判断候选源的兼容性

**接收：**局部响应、窗口 `(x,y,side)` 和待查询候选源坐标。

**需要完成：**

1. 支持不同尺寸的观察窗口，并保留其在全场中的位置和范围。
2. 提供候选坐标的 Fourier 特征表示。
3. 输出条件能量 `Eθ(O,v,s)`：越能解释观测的候选，其能量越低。
4. 在给定候选集合上，将负能量转为学生分布 `pᵢ ∝ exp(−Eᵢ)`，供训练和评价使用。

**交付：**可调用的学生模型，以及不同窗口大小下的评分和分布示例。

**完成目标：**模型能查询新的连续候选位置；预测不依赖物理重渲染。真实源、完整场景几何、障碍物掩码和完整四分树不作为学生输入。原始坐标对比可作为补充实验，不需要单独建文件。

### 3.6 `train.py`：让学生拟合教师分布

**接收：**训练与验证观测、对应教师目标、学生模型和训练设置。

**需要完成：**

1. 将观测与正确的教师记录对应起来，在同一候选集合上比较教师与学生分布。
2. 以分布拟合为训练目标，而不是把真实源坐标作为唯一回归标签，也不要求能量数值逐点等于物理代价。
3. 记录训练和验证表现，保存模型及对应运行配置。
4. 先验证少量样本能够被学习，再扩大训练规模；模型选择只使用验证集。

**交付：**`outputs/checkpoints/` 中的模型、配置和训练记录。

**完成目标：**能证明学生学到了教师给出的兼容性结构，而不只是流程可以运行。训练结果可恢复，并能交给 `evaluate.py` 在未见场景上评价。

### 3.7 `evaluate.py`：验证 proposal 的研究主张

**接收：**未参与训练的场景观测、教师结果、训练后的模型及实验设置。

**需要完成：**

1. 在共同候选范围上，比较学生分布与教师分布，并报告预测位置的物理兼容性。
2. 检查模糊观测下是否保留合理的多解；展示单条有效边界与两条独立边界的典型结果。
3. 评价未见场景、未见障碍物组合上的表现，并按窗口大小区分结果。
4. 完成 `Lresp` 与 `Lresp + Ledge` 的必要消融，以及均匀与自适应搜索的质量/成本对比。
5. 输出图像和简明报告，记录失败案例、实验设置与结论。Fourier 对比、仅窗口信息基线作为补充，不阻塞第一轮流程。

**交付：**`outputs/figures/` 中的观测—教师—学生对比图，以及 `outputs/reports/` 中的指标和报告。

**完成目标：**回答模型是否恢复了正确的源空间约束与不确定性，边界项是否有独立收益，自适应搜索是否降低成本。单点坐标误差不能代替这些证据；第二条边界也并非在每个场景中都必然使分布集中。

### 3.8 `checks.py`：验证各文件能正确交接

**接收：**少量真实 RIND 样本及以上模块。

**需要完成：**检查窗口和数据划分、真实源重渲染、候选与概率对应关系、模型对不同大小窗口的处理，以及从一个观测生成教师目标再交给学生的完整链路。

**交付：**简短的通过/失败结果，失败时指出问题所属阶段。

**完成目标：**全组共享一个小规模检查入口，无需为每个内部函数单独规划测试文件。各模块负责人补充自己负责阶段的检查，不额外设立测试工作组。

## 5. 最少的数据交接约定

| 交接内容 | 至少包含 |
|---|---|
| 观测样本 | `scene_id`、`view_id`、`response`、`window=(x,y,side)` |
| 教师监督 | 样本标识、`candidate_xy`、有效性信息、`physical_cost`、`teacher_prob`；非均匀候选附带权重 |
| 学生结果 | 对应候选的 `energy` 和 `probability`，以及模型/配置标识 |

场景为 `[0,1024]`，x 向右、y 向下；数组按 `[行,列]` 访问。场景 ID、真实源和几何可以随记录保存，但不得作为学生输入。

**保留三项必要假设说明：**

- 窗口来自源驱动的四分树，因此位置和大小本身包含定位信息。先明确这一观测机制；“源必须位于窗口父节点内”的额外候选限制不属于原始 proposal，当前默认不启用。
- 教师知道隐藏场景几何，学生不知道；相同输入可能对应不同场景的教师结果，因此不能保证学生精确复原每个场景的教师分布。
- 教师通过几何排除障碍物内候选。若评估学生时也使用这种教师提供的有效范围，必须注明；不能将其描述为完全无需几何的部署结果。

## 6. 自行认领与周四目标

第一轮截止 **2026 年 10 月 1 日（周四）**。人员和算力待定，组员填写姓名认领。任务可以合并，不必每个文件分配一个人。

| 任务 | 文件 | 负责人 | 周四最小交付 |
|---|---|---|---|
| A 数据 | `data.py` | 待认领 | 一小份新单源数据、窗口示例和场景划分 |
| B 物理监督 | `physics.py`、`teacher.py` | 待认领 | 真实源重渲染验证，以及一个观测的响应代价图和教师分布 |
| C 候选搜索 | `search.py` | 待认领 | 可用的均匀候选集；明确自适应搜索的下一步交付 |
| D 模型与训练 | `model.py`、`train.py` | 待认领 | 不同窗口大小的候选评分；教师就绪时完成小规模训练验证 |
| E 评估与汇总 | `evaluate.py` | 待认领 | 一张教师结果图、评价项目清单和已完成模块汇总 |
| 共同检查 | `checks.py` | 各模块负责人 | 验证已完成部分，列出未接通的环节 |

依赖顺序为：**A → B/C → 教师目标 → D → E**。B 与 C 先约定候选格式和物理评价输入；D 可先验证模型输入输出，E 可先检查教师结果。

每人交付时只需说明：**文件在哪里、已实现什么、结果证据是什么、还缺什么。**周四的设计说明或占位代码必须与已运行结果区分。

## 7. 最终需要完成到什么程度

Phase I 最终成果应包括：新单源数据与正确划分、可验证的物理教师、条件能量学生、分布拟合训练、未见场景评价、边界项消融，以及自适应搜索的质量与计算成本对比。

第一轮先打通 **一个观测 → 候选物理代价 → 教师分布 → 学生评分 → 可视化**，随后扩展训练和实验。首轮只做必要链路，不等于删去 proposal 中后续必须验证的研究内容。
