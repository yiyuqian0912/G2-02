# 自选测试视窗与逐像素概率图

推荐使用新的交互结果浏览器：

```bash
./view_results.sh
```

打开 **http://127.0.0.1:8767**。若端口被占用，运行 `./view_results.sh --port 8777`；关闭服务按 Ctrl+C。它只监听本机，不上传数据。已有 `train5000` 和 `round1_cpu` 可直接选；新实验产生 best.pt 和 records.json 后也会被发现。

## 操作

1. 选择实验、response/edge 和 seed。
2. 按 size、场景、响应类型筛选，在“局部视窗”中选择 test observation。编号 #index 是该实验测试清单中的索引，不是整个发布包的全局索引。“有响应变化”方便查找边界，但不等于存在特定数量的独立边界。
3. 选择密集或相同候选模式、模型查询间距及归一化范围，点击“生成对比”。上一/下一按钮只改变选择，需要再次生成；已显示结果的标题一直标明实际对应的 scene/view。
4. 在三幅图上悬停查看像素响应或候选概率；可切换线性/对数色标、教师概率/物理代价、放大及真实源标记。
5. 下载各图 PNG，或下载完整数值 NPZ。颜色只用于显示，判断很小的概率应看悬停数值/NPZ。

## 三幅图分别表示什么

| 面板 | 数据来源 | 要看什么 |
|---|---|---|
| 局部响应 | 原始 size×size 观测 | 是否有边界、边界位置、观察窗口在世界中的位置与尺度 |
| 模型预测 | 当前 checkpoint 对每个所选源坐标直接计算能量 | 多解、集中区域、非物理伪影；逐像素模式不是放大稀疏散点 |
| 教师采样 | 该实验已保存的物理候选及 q/cost | 物理上兼容哪些实际采样点；没有新渲染或插值出来的“教师像素真值” |

spacing=1 时学生查询每个 1×1 源像素中心，共 1024² 个坐标；spacing=4 时是 256²；spacing=64 时是 16²。查询密度可以人为控制，无需重训。但改变推理密度**不会增加训练监督**，也不能修复旧模型的混叠。默认候选 chunk=256 以限制推理内存；大 size 的逐像素查询更慢。

**密集模式：**学生、教师各自在自己的候选集合内归一化，色标也各自标注。不应直接比较两个图单点概率的高度，因为点数不同。需要公平数值比较时使用“相同候选点”模式。

**相同候选模式：**学生重新查询教师原始候选坐标；两者在同一候选集合上比较，概率图共享色标。下方 KL/L1/兼容质量/invalid mass 始终来自这一共同候选比较，即使上方正在显示更细的学生图。

**公开范围 world：**仅排除观测窗口，学生不能用隐藏障碍物几何删除错误预测。**几何辅助 geometry：**再排除真实障碍物，是额外诊断。页面默认使用 checkpoint 的训练范围；切换后会提示结果范围不同。真实源绿色十字仅供评估，不参与能量或概率计算。

灰色表示当前范围外或没有可显示代价；教师物理无效点的 q=0，概率图显示黑色。候选中所有代价都高时 q 仍然归一化为 1，因此请同时查看教师 cost。局部原始响应不额外叠加障碍物颜色，避免把未输入模型的信息误认为响应。

## 导出内容

服务只读取实验，生成的结果暂存在内存。点击下载后保存位置由浏览器决定。NPZ 包含学生概率/能量/支持掩码、局部响应/window、真实源（仅诊断）、教师真实坐标/q/cost/valid、共同候选学生概率和元数据。数值为真实计算结果，未乘面积；source-space y 向下。PNG 带当前选中的定位叠加，未包含数值矩阵和色标文字，分享时请附 spacing、范围和色标最大值，或同时分享 NPZ。

旧的静态导出入口继续保留：

```bash
PYTHONPATH=.:src .venv/bin/python scripts/dense_probability.py \
  --root outputs/experiments/train5000 --variant response --seed 0 \
  --indices 3 --support world
```

它在对应 seed 的 `dense/` 下输出 `.npz`、原生 `.pixels.png`、带标签的 `.png` 和可独立打开的 `.html`。可用 `--help` 查看其他参数。静态导出与交互页面使用同一套密集评分函数。

旧 train5000 的训练最高 Fourier 周期与 spacing 都为 64，不能用其逐像素波纹证明物理结构恢复。新默认配置降至四个频率，并新增验证细网格 probe；方法变化仍需要新训练。
